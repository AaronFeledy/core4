## Codebase Patterns

- Nested Landofile authoring aliases: model them as a `Schema.transform` whose `from` schema declares
  mutually exclusive `Schema.Union` variants, with `Schema.optional(Schema.Never)` anti-fields for
  every competing spelling. Keep the canonical variant first so canonical output survives a second
  decode. Annotate the `from` union so its description survives into `ServiceConfigInput` and the
  published artifact.
- A nested `Schema.Struct` publishes `additionalProperties: false`, so unknown nested keys fail closed
  under both default and strict decode and surface as path-precise lint violations.
- After any `ServiceConfig` field change, run `bun run codegen:schema-snapshot` early: it refreshes
  `dist/schemas`, `dist/command-schemas`, and `docs/reference/schemas`, and it runs the
  public-field-description gate.
- Keep `@lando/sdk/network-trust` path-only and file-IO-free. Core's shared `loadCaPems` seam owns
  UTF-8 PEM loading, stable digests, and the tagged path/remediation failure; consumers map that
  failure into their own boundary errors rather than reading CA files again.
- Friendly single-name config aliases belong in `FRIENDLY_ENV_OVERLAYS` after the generic overlay;
  reuse `parseOverlayValue` so JSON booleans become typed values and malformed input fails at
  `GlobalConfig` decode instead of adding a second parser.
- A default service feature that will later receive planner-seeded config must decode `{}` and apply
  as a no-op until that config is present; base composition runs before later planner-wiring stories.
- When a planner configures one base-default feature, keep unconfigured defaults on
  `base.defaultFeatures` and move only configured refs through `ComposeServiceFeature`; this preserves
  established base semantics while allowing schema-decoded planner payloads.
- Provenance stored beside decoded Landofile objects in a `WeakMap` must be copied whenever an include
  resolver or normalization step returns a replacement object; otherwise downstream cache keys silently
  lose source dependencies.
- Keep host-path-bearing build descriptors outside artifact-key projection: key immutable content through
  `buildKeyInputs`, then re-read and verify those bytes before the first provider build request.

## Ownership notes (spec-derived, easy to get wrong)

- lando.boot (priority 100) owns only the /etc/lando/* DIRECTORY scaffold, baked into the artifact.
- lando.env (priority 700) owns /etc/lando/environment content, env.d/, per-exec sourcing, and the
  LANDO_LINUX_* distro exports. It already ships at plugins/service-lando/src/features/env.ts.
- LANDO_CA_BUNDLE is always /etc/lando/certs/ca-bundle.pem, before and after the first rebuild.

    the summary builder forwards it onto `SummarySection.notes`, and only a decorated-frame render test
    catches that omission. Assert the framed surface, not just the result field.
  - Temporary guard mutations used for RED proof are only safe while nothing else can commit the
    worktree; verify the specific hunks in the diff immediately before committing so a mutation left in
    place cannot ship inside a story commit.
