## Codebase Patterns

- The disposition matrix (US-466) is the single classification source: coverage gate, docs matrix, rejection remediation text, and conformance skip-list are all derived artifacts. Never hand-maintain a second key list.
- The vendored Compose schema is a coverage oracle, not a codegen source: Effect Schema in @lando/sdk stays hand-authored per spec §1.2.
- Pin source is a compose-go tag (compose-spec/compose-spec is an untagged mirror; never pin to it).
- Keep the networked `codegen:compose-vendor` refresh outside generic offline `codegen`; tests and coverage gates read only committed bytes.
- The vendored upstream schema is checksum-pinned byte-for-byte and excluded from formatting; format the pin and tooling, never the schema payload.
- `Schema.encodedBoundSchema` drops property-signature annotations for fields backed by `Schema.transform`, so a description set only at the field site never reaches `ServiceConfigInput` or its published artifact. Annotate the transform's `from` schema as well.
- Treat a public-schema annotation exemption as a last resort, not the standard remedy: exemptions are permanent and unpoliced, so an exempted field keeps passing after its description is deleted. If a gate flags a field whose generated artifact already carries the metadata, fix the gate's traversal instead.
- Top-level Compose dispositions need AppPlan-specific rationales; `configs` and `secrets` are preserved because AppPlan has no provider-neutral fields for them.
- Landofile decode runs twice (per-file, then over the merged result with `onExcessProperty: "error"`), so every `ServiceConfig` field transform must accept its own canonical output as input. Pair each new alternate-form field with a `decode(decode(x)) === decode(x)` test; an encode round-trip test alone will not catch the second pass.
- A per-command oclif `--format` `options:` list does not validate anything: the universal resolver strips `--format` before oclif parses and reinjects `flags.format`. Real validation is `RESULT_FORMATS` in `core/src/cli/format-flags.ts`, so a command silently ignoring a format is a bug in its own option mapping, not in the flag declaration.
- A new or changed static oclif flag is inert until `bun run codegen:oclif-manifest` runs: `--help` and compiled-path flag validation both read the generated `compiled-manifest.ts`. `core/oclif.manifest.json` is gitignored; `compiled-manifest.ts` and `docs/reference/commands.mdx` are the committed artifacts.
- Build multi-form schema test fixtures by decoding an ENCODED document through the schema and asserting against the decoded result, rather than hand-writing canonical decoded values. It removes a whole class of wrong-by-guess assertions and makes the test prove canonicalization instead of assuming it.
- `Pick<T, "a"> & { readonly b?: B }` is not interchangeable with `Pick<T, "a" | "b">` under `exactOptionalPropertyTypes`: the hand-written optional excludes `undefined` and rejects the real source type. Spell narrowed views as a `Pick` of the source so optionality stays identical.
- The app-plan cache key deliberately omits provider capabilities, so any capability gate must also run on the cached-plan path; and any change to planner OUTPUT semantics needs an `APP_PLAN_CACHE_SCHEMA_VERSION` bump, because the key is derived from the authored Landofile and will not roll on its own.
- Biome scans untracked sibling checkouts. A stale `.worktrees/` directory is git-excluded and invisible to `git status`, yet makes `bun run lint` fail on files outside the change; scope Biome to tracked package dirs before believing a repo-wide lint failure.
- `bun test <path>` treats its argument as a filter, not a path: a wrong or moved path emits a "did not match any test files" diagnostic and exits nonzero. Scripted spot-check loops must require both command success and a positive test count; never infer a pass only from the absence of failures.
- The machine-output envelope narrows every error to `{_tag, message, remediation}` by design. Structured error context belongs in the message and in the bug-report formatter's extra fields, not in a per-error widening of the shared envelope.
- Schema parse-error messages can reach the plain terminal renderer unchanged. Never interpolate raw Landofile values into those messages; use constant grammar/remediation text so control bytes cannot alter terminal output.
- Include resolution has two distinct roots: the app root is the containment boundary, while the including fragment's directory is the base for relative sources. Never reuse one as the other; preserve absolute source identity separately from authored provenance.
- A key classified `preserved` is not implemented until the authoring schema accepts it: Landofile decode uses `onExcessProperty: "error"`, so an unaccepted-but-preserved key fails as an unsupported MVP key rather than round-tripping. Compose rejection runs before schema decode, so only `rejected` matrix paths yield `ComposeKeyRejectedError`.
- Three fail-closed Compose capability refinements sit under `composeSpec: "native"` and must not be merged or inferred from the tier alone: (1) exact 24-key `ComposeServiceKnobKey` via `composeKnobs.supported`, (2) service-level families via `composeServiceFields.supported` (`networks`, `configs`, `secrets`, `profiles`, `labels`), (3) exact matrix-preserved descendants via `composePreservedPaths.supported` (initially `depends_on.*.restart`, `healthcheck.start_interval`). Service-level `x-*` remains preserved-inert without capability gating.
- Manual CLI verification must invoke `core/bin/lando.ts`; running `core/src/cli/index.ts` directly emits nothing and exits 0, which is indistinguishable from a passing command.
- A derived/computed invariant (skip-list, drift manifest, anti-hiding guard) is unproven until it has been observed failing. Mutate an input to manufacture the stale or hidden state, confirm red, then restore; a guard that has only ever been green is indistinguishable from one that cannot fail.
- An `*.integration.test.ts` gated on an env var is dead unless something sets it. Pair the skip guard with a generator-emitted export in the CI workflow and assert the ordering between the export and the test invocation, otherwise the lane silently never runs.
- Checksum pinning authenticates vendored fixture bytes but does not make fixture-derived paths safe. Keep materialized files inside a canonical temporary root, reject symlink escapes, and create files without following or overwriting existing destinations.
- Only `prd.json` is machine-read, so an adjudication amendment does not update the narrative `prd-compose-0*.md` source automatically. Reconcile both in the same pass by comparing criterion counts and asserting normalized string equality after folding documented synonyms; an amendment can add a criterion as well as change wording, and eyeballed similarity lets the source contract silently drift. First establish whether reconciliation is owed at all: an adjudication may decide "no change to `prd.json`", and then the narrative is already current. Compare the marker's decision line against `git log -1 -- spec/compose/prd.json`; treating reconciliation as unconditionally owed invents an edit and reports a divergence that does not exist.
- A named-volume `subpath` must exist before Podman mounts it. Live fixtures that exercise subpaths need an initializer container before application bring-up; do not remove the subpath merely to make the fixture runnable.
- When stories share a conformance harness, distinguish ownership of the shared runner and tooling from ownership of fixtures and fixture-specific assertions; executing another story's proof does not transfer its scope.
- Compose conformance has no static skip-list file: a fixture is treated as rejected only when runtime classification from the disposition matrix says so, and `manifest.json` is purely the drift record. An audit that greps for a skip-list artifact reports a false MISSING; re-falsify the manifest parity guard instead.
- One mutation that turns two guards red proves complementary detection, not guard independence: the same deleted input can violate both predicates at once. The claim the evidence supports is "a targeted mutation activated two complementary guards while unrelated assertions stayed green"; real independence needs one mutation per guard, each leaving the other violation exposed. Do not upgrade the weaker observation to an independence claim in the record.
- The dependency-free Landofile parser intentionally stays a YAML subset. Resolve native anchors, aliases, and merge keys after subset parsing but before schema decode; do not switch wholesale to `Bun.YAML.parse`, which enables unrelated YAML surfaces. Once `<<:` is legal syntax, tag detection must inspect merge-key values so `!reset`/`!override` keep their Compose rejection shape.

The sidecar has to be re-attached at each seam that produces a NEW object — the merged decode in `resolveTree` and the layer merge in the Landofile service — or it silently disappears exactly where the value is finally consumed.
