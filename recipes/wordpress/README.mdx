# WordPress

Spin up WordPress with PHP and MariaDB, plus WP-CLI and Composer.

```sh
lando init --recipe wordpress --name=my-wordpress-app --yes
lando start
lando info
```

`lando start` prints the app URL. `lando info` repeats it. TODO: capture

The walkthrough below scaffolds the recipe, starts the app, and tears it down.
