# LEMP

Spin up Nginx, PHP, and MariaDB for a traditional PHP app.

```sh
lando init --recipe lemp --name=my-lemp-app --yes
lando start
lando info
```

`lando start` prints the app URL. `lando info` repeats it. TODO: capture
