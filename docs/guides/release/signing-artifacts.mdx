# Signing release artifacts

Release signing uses different tools for each platform:

| Platform | Signing tools or artifacts |
| --- | --- |
| macOS | Developer ID, `notarytool`, and `stapler` |
| Windows | Authenticode `signtool` plus keyless `cosign` |
| Linux | GPG/cosign checksum manifests |

For the release procedure and credentials, use
[the contributor release workflow](../../contributing/release.md).
