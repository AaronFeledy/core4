# Release compiled bytecode budget

## Bytecode compile budget

The release-orchestrator tests inject the runner and clock so this guide stays host-safe and does not compile every platform binary during docs tests.

Stage 7 compiles the canonical CLI entry (`./core/bin/lando.ts`).

Every release binary is compiled with Bun bytecode enabled.

```sh
--compile --bytecode
```

Compile targets match the Beta 1 CI platform ids (`darwin-arm64,darwin-x64,linux-arm64,linux-x64,windows-x64`).

The reference cold-build budget is enforced on linux-x64.

A linux-x64 compile over 10 minutes fails the release with a tagged budget error (`600000ms`).

Local rehearsal prints compile duration before later credential-gated signing stages warning-skip.

```json
[release] compile linux-x64 completed in <duration>ms (budget 600000ms)
```
