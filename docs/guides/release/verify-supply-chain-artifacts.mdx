# Verify supply-chain artifacts

Stage 12 emits CycloneDX JSON 1.6 SBOM files for publishable release
artifacts. Each binary and library archive receives an artifact-specific
SBOM path of the form `dist/lando-<artifact>-<version>-sbom.cdx.json`.
Each SBOM carries the release artifact identity, checksum, package
components, Bun runtime component, and generator metadata.
