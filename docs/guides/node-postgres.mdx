# Scaffold a Node and Postgres app

After [installing Lando and completing setup](./install/path-and-setup.mdx), initialize the bundled `node-postgres` example in a separate directory. It creates a small Node server and a Postgres service. Run `lando start` from the directory containing the generated `.lando.yml`:

```sh
lando init --recipe node-postgres --name=node-postgres --yes
cd node-postgres
lando start
```

`--yes` is consent. It skips prompts. It does not pick a provider.

The default provider is `lando` (managed Podman). If default setup fails and you have working system Docker, run `lando setup --provider=docker`. See [Pick a container provider](./setup/provider-selection.mdx).

## Read the scaffold

The recipe writes three files.
It does not run a package manager after init.

The `web` service uses `node:lts`, publishes container port 3000 on host port 3000, and mounts the app root at `/app`. The `database` service uses Postgres. The example server replies `Hello from Lando`; replace it with your own application code.

## Use another recipe

For another starting stack, use a bundled recipe such as `drupal`, `drupal-cms`, `lamp`, `lemp`, `toolbox`, or `wordpress`.
