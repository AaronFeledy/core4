# Start an app with no services

A Landofile can declare only `name:` and skip `services:` entirely. `services:` is independently optional alongside `tooling:` and `includes:`.

```yaml
name: zero-services
```

Useful when you want a CLI-wrapper app with no containers of its own, or when `includes:` pulls services in from elsewhere.
