# Zero services

A Landofile can declare only `name:` and no `services:` block at all.
`services:` is independently optional alongside `tooling:` and `includes:`.
A Landofile can skip `services:` entirely and only declare `tooling:`,
useful for a pure CLI-wrapper app with no containers of its own. It can also
declare only `includes:` to pull in services, tooling, or config fragments
from elsewhere instead of defining them locally.
