# Verify the installer scripts

> **Alpha status:** Published installer URLs are **not live**. `get.lando.dev` is not serving v4 installers. See [Alpha install and bug reports](../../alpha-install-and-bug-reports.md).

Do not pipe a get.lando.dev URL into a shell. Those hosts are not up.

The scripts in this repo (`scripts/install.sh`, `scripts/install.ps1`) will one day fetch a signed channel manifest. They do not work without `https://update.lando.dev`.

## Published URLs (not live)

| Script | Planned URL |
| --- | --- |
| POSIX installer | `https://get.lando.dev/install.sh` |
| Windows installer | `https://get.lando.dev/install.ps1` |

Treat those as reserved names, not download links. For a binary you can run today, use a Linux x64 `v4.0.0-dev.N` prerelease and check `SHA256SUMS` as [Install from a GitHub release](./github-releases.mdx) describes.

When installer signatures do publish, release notes will carry the exact `cosign` or `gpg` command. Until then, there is no trust root URL to copy from this page.
