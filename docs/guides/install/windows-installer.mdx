# Windows installer

## Platform detection

The PowerShell installer maps a Windows x64 host (`AMD64`) to the
`windows-x64` release artifact. Other architectures, like ARM64, aren't
supported and fail before any binary downloads.

## Channels

`stable` is the default channel manifest, resolved from
`https://update.lando.dev/v4/stable.json`. Set `LANDO_CHANNEL=next` or
`LANDO_CHANNEL=dev` to install from a different channel.

## Verify and install

The installer downloads `lando.exe`, a `SHA256SUMS` checksum manifest, and
its cosign signature and certificate (`SHA256SUMS.sig`, `SHA256SUMS.crt`),
then verifies the manifest against the installer-vendored cosign trust root:

```powershell
cosign verify-blob --certificate-identity-regexp <installer-trust-root> --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

Only a verified binary gets installed. It lands at
`${LANDO_INSTALL_DIR:-<userDataRoot>\bin}\lando.exe`, creating the directory
if it doesn't exist.

If PowerShell blocks script execution, the installer prints the exact
remediation:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```
