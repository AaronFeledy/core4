# Install Lando on Windows

> **Alpha status:** There is no Windows `lando.exe`, and the PowerShell installer is **not live**. `https://get.lando.dev/install.ps1` is not serving v4. See [Alpha install and bug reports](../../alpha-install-and-bug-reports.md).

On Windows today, install the Linux x64 `v4.0.0-dev.N` binary **inside WSL**. That is the same binary as native Linux. Follow [Install Lando on WSL](./wsl.mdx) or [Install from a GitHub release](./github-releases.mdx).

The script at `scripts/install.ps1` exists in this repo. It still needs live channel manifests at `https://update.lando.dev` and a published Windows binary. Neither is shipping.

When those hosts are up, the script will map an AMD64 host to `windows-x64` and fail other architectures before any download. Do not run a get.lando.dev URL now.

Do not pass `--provider=docker` to "get Windows working." The default provider is `lando` (managed Podman). `--yes` is consent, not a provider switch.
