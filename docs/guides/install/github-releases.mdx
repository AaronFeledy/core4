# Install from a GitHub release

Every Beta 1 platform target — `linux-x64`, `linux-arm64`, `darwin-x64`,
`darwin-arm64`, and `windows-x64` — publishes a signed, compiled binary
asset. Download the one for your platform and you're done: the binary embeds
Bun, so manual installs don't need a separate Bun, Node, npm, yarn, or pnpm
runtime.

File sync is the one thing that isn't embedded. Mutagen's host tools and
agents get pulled in when you run `lando setup`.

## Verify what you downloaded

Checksum manifests (`SHA256SUMS` and `SHA512SUMS`) and their GPG/cosign
signatures publish beside every binary. Each binary and library archive also
ships a linked CycloneDX SBOM and SLSA provenance asset, so you can trace
supply-chain provenance end to end. Verification instructions are published
alongside the release assets in `release-notes.md`.
