# Install from a GitHub release

> **Alpha status:** Alpha ships six unsigned `v4.0.0-dev.N` GitHub assets
> (`linux-x64`, `linux-arm64`, `darwin-x64`, `darwin-arm64`, `windows-x64`,
> `windows-arm64`). Signed binaries, GPG, SHA512, SBOM, and installers are
> **not yet implemented**. See [alpha install and bug
> reports](../../alpha-install-and-bug-reports.md) for current install options.

Every platform target (`linux-x64`, `linux-arm64`, `darwin-x64`,
`darwin-arm64`, `windows-x64`, and `windows-arm64`) publishes an unsigned
compiled binary on the GitHub prerelease. Download the one for your platform.
The binary embeds Bun, so manual installs don't need a separate Bun, Node,
npm, yarn, or pnpm runtime.

File sync is the one thing that isn't embedded. Mutagen's host tools and
agents get pulled in when you run `lando setup`.

## Verify what you downloaded

Alpha publishes `SHA256SUMS` beside every binary. Checksums, GPG/cosign
signatures, SHA512, CycloneDX SBOM, and SLSA provenance stay later. Follow
[alpha install and bug reports](../../alpha-install-and-bug-reports.md) to
check only the asset you downloaded (`grep ' lando-linux-x64$' SHA256SUMS | sha256sum -c`).
