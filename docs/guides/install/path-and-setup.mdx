# Installer PATH and setup

## PATH guidance

The POSIX installer prints the exact snippet to add to your shell profile:

```sh
eval "$(<userDataRoot>/bin/lando shellenv)"
```

The PowerShell installer prints the equivalent for PowerShell profiles:

```powershell
& '<userDataRoot>/bin/lando.exe' shellenv --shell=powershell
```

Both set `LANDO_USER_DATA_ROOT` and put `lando` on `PATH` for the current
shell.

## Post-install setup

By default the installer leaves `lando setup` for you to run later. You can
change that with an environment variable:

| Env var | Effect |
| --- | --- |
| `LANDO_INSTALL_RUN_SETUP=1` | Run `lando setup` immediately after the verified binary installs |
| `LANDO_INSTALL_SKIP_SETUP=1` | Explicitly skip post-install setup |
| `LANDO_INSTALL_NONINTERACTIVE=1` | Skip post-install setup without prompting |
