# Scripting with JSON

Every non-interactive Lando command accepts `--format json` and emits one
`CommandResultEnvelope` on stdout. `--format=json` is equivalent, `--json`
is a global shorthand injected by the adapter, and `-j` is the single-
character shorthand. On success the envelope wraps the command's typed
result under `result` with `ok: true`; on failure it carries the tagged error
JSON under `error` with `ok: false`. A global `apiVersion: "v4"` identifies
the wire contract, and the redaction service runs before emission so secrets
never appear in machine output.

Streaming commands such as `app:logs` and `app:exec` emit `StreamFrame`
frames under `--format json` and terminate with a single result frame.
Source and compiled `--format json` are identical because both use the same
native registry and dispatcher.

## Envelope contract

The universal machine-output flag aliases are `--format json`,
`--format=json`, `--json`, and `-j`. The failure envelope has the shape
`{ "ok": false, "error": <tagged-error> }`; a failing command preserves
its non-zero exit code alongside the envelope so scripts can branch on both.
The tagged error exposes a machine `_tag` plus human remediation, so an
agent can react to the failure class without scraping prose.

The generated command reference lists every public command and documents the
universal `--format json` flag once in its machine-readable output section.
