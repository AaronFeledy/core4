# Embedding defaults

## Library defaults

Library runtimes use the silent logger by default.

Library runtimes provide a json renderer service by default.

Telemetry is disabled unless the embedder opts in (`off`).

The root entry installs no bundled plugin modules; plugin discovery is host-provided only by default (`explicit`).

## Library overrides

Embedders can override the renderer field at runtime construction (`plain`).

Embedders can opt into telemetry at runtime construction (`true`).

Embedders can import @lando/core/bundled-plugins before runtime construction to opt into bundled-only loading.

Host plugin layers are built once and override matching generated runtime services.

Resolved plugin manifests register contributions without enabling external imports.

## Library import boundary

Embedders import makeLandoRuntime from the default package entry (`@lando/core`).

OCLIF is development-only; the private CLI spec directories contain native metadata/adapters and manifest tooling, and no published package specifier exposes them (`not-published`).

The library default JSON renderer does not pull TUI paths into the default entry.
