# CLI deprecation warnings and suppression

The first use of a deprecated warn-level surface renders a human warning through the active
renderer. Later uses of the same `kind/id` don't spam more warnings; the end-of-run summary retains
the total use count.

Suppress human renderer warning output for the current invocation with `--no-deprecation-warnings`,
or for scripts and CI with `LANDO_DEPRECATION_WARNINGS=0`. Machine-readable summaries and JSON
`deprecation-used` diagnostics remain available to commands that report them.

In JSON mode, deprecation use is written as structured stderr with the canonical payload shape:

```json
{
  "_tag": "deprecation-used",
  "use": {
    "kind": "…",
    "id": "…",
    "notice": "…",
    "timestamp": "…"
  }
}
```
