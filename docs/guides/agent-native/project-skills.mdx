# Install project-local agent skills

Run `lando agent:skills:install` from your app directory to give agents
project-local instructions for using Lando tooling. The command writes
`.agents/skills/lando/SKILL.md`; check that file to confirm the pack is installed.

The commands below install, update, and remove the pack. Choose the action you
need rather than running all three: the last command removes the owned file.
Update refreshes the file only while Lando still owns it; a file you adopted
or wrote by hand stays put.

```sh
lando agent:skills:install
lando agent:skills:update
lando agent:skills:remove
```

The pack is `.agents/skills/lando/SKILL.md`. It tells agents to prefer
`lando <tooling>`, `lando exec`, and `lando mcp`, and to detect in-container
vs host. It points at the existing [MCP](/core4/guides/agent-native/mcp/),
[in-container context](/core4/guides/agent-native/in-container-context/), and
[exec](/core4/guides/cli/exec/) guides. It does not copy those pages.

`lando start` and `lando rebuild` do not install agent skills. For a new app,
pass `--agent-skills` to `lando init`; installation is off by default.

## Init stays off unless you ask

```sh
lando init --name=demo --recipe=toolbox --yes --no-interactive
lando init --name=demo-with-skills --recipe=toolbox --yes --no-interactive --agent-skills
```

The first command writes the recipe only. The second also installs the pack
into the new app directory.
