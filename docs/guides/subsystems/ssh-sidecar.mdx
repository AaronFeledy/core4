# SSH sidecar

This page is a contributor SDK dump for `SshService`. It stays off the user nav.

The only Landofile knob is top-level `sshAgent` with `sidecar: true`:

```yaml
name: myapp
sshAgent:
  sidecar: true
```

`sidecar: false` is rejected. There is no per-service `sshAgent` key.

Lando starts the sidecar with the global app when a start needs it. You do not start an SSH agent by hand.

This is not a user how-to. For a shell inside a service, see [Open a shell in a service](../cli/ssh.mdx).
