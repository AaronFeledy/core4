# Run lando doctor

```sh
lando doctor
```

Doctor reports whether setup, the provider, the proxy, certs, and related checks are healthy. A failing section does not abort the rest of the report.

Run it after `lando setup`. The default provider is `lando` (managed Podman). After a successful `lando setup --provider=docker`, bare `lando doctor` stays on Docker. `LANDO_PROVIDER` does not persist.

## Read the report

Doctor runs one section at a time under the same live task list `lando start` paints: `✓` for a clean section, `!` when it passed with warnings, `✗` when a check failed or doctor could not run the section. Below that, the report lists only the checks that need you, each with a `↳` line saying what to do. Most point you at `lando setup`. The `Next` list at the bottom collects those commands.

Passing checks stay out of the way. To see every check, including the ones that passed:

```sh
lando doctor --all
```

| Check | What to do |
| --- | --- |
| proxy | Run `lando setup`, then start an app so Traefik can route. You do not start Traefik by hand. |
| preferred-host-ports | Something else owns 80 or 443. Read the selected fallback ports with `lando info`. Stop the holder or choose free router ports, then run `lando global:restart`. |
| certs | Run `lando setup` to install and trust the local CA. |
| setup readiness | Rerun `lando setup` to resume the first failed step. |
| accelerated-start | In the reported app root, run `lando start` to recover a retained attempt or interrupted recovery, or `lando destroy` to discard it. |

Default setup may fail on Alpha. If doctor names a host prerequisite, fix it and rerun `lando setup`. If the managed runtime still cannot install and you have working system Docker, run `lando setup --provider=docker`.

`lando setup` and `lando setup --yes` ignore leftover `defaultProviderId` in user config.

## Recover a retained or interrupted accelerated start

```sh
lando doctor --format=json
```

An `accelerated-start` check lists the app ID, app root, phase, attempt ID,
recorded sessions and volumes, and journal path. It scans saved attempts across
apps, even without `--app`. `doctor --fix` reports these records but does not
start or destroy apps for you. An interrupted recovery also shows
`recoveryState: interrupted recovery` and `recoveredFrom`, the original attempt
ID. You can retry it even if its phase is `preparing`, `sessions-ready`, or
`apply-intent`: Lando preserves that recovery marker across retries.

For a `retained` attempt or an interrupted recovery, change to the reported app root and run:

```sh
lando start
lando info
```

Recovery requires the same mount plan, provider, and file-sync engine. Lando
terminates the recorded sessions without flushing their stale contents back to
your host. It then reseeds the targets from your host with `one-way-replica`
before creating normal sessions. Unknown sessions or an engine without that mode
block recovery. Stop, restart, and rebuild remain blocked until you recover or
discard the attempt.

To discard a retained attempt or interrupted recovery instead, use `lando destroy`. This terminates its
recorded sessions without copying target data to your host. Volumes stay unless
you explicitly request their removal. **`--volumes` deletes app volume data**;
use it only when you intend to discard that data too. Pending first attempts
without a recovery marker are not automatically recovered or discarded.
Keep the journal and inspect its resources rather
than deleting the file by hand.

## Check the current app

```sh
lando doctor --app
```

That adds Landofile lint and version-constraint checks for this app. A missing or invalid Landofile shows up as its own section. The rest of the report still runs.

## Machine-readable output

```sh
lando doctor --format=json
lando doctor --format=yaml
```

Use those formats in scripts. Both wrap the report in the standard result envelope under `result`, so `ok` and the tagged `error` are always there to branch on. Doctor redacts secrets, certificate bodies, and proxy URLs.

## Verify

```sh
lando doctor
lando --version
```

Doctor should name the provider you selected.
