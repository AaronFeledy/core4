# Resolve lndo.site on this machine

`lando setup` writes `*.lndo.site` into this machine's DNS so app URLs resolve on localhost. You do not start a host proxy.

```sh
lando setup
```

On Linux that write is an `/etc/hosts` block or a systemd-resolved drop-in. The default domain is `lndo.site`. The default address is `127.0.0.1`.

Other devices on the LAN do not get that DNS entry. To reach an app from another device, bind a port on purpose. See [Reach an app from another device](./external-access.mdx).

## Manage DNS yourself

If you already own DNS (corporate split-DNS, dnsmasq, or your own `/etc/hosts` entries):

```sh
lando setup --host-proxy=none
```

That skips the privileged DNS write.

## Verify

```sh
lando doctor
```

Doctor reports host-proxy as informational when you opted out. A missing `*.lndo.site` resolution on this machine usually means you still need `lando setup`, or you opted out.
