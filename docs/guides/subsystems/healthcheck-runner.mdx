# Healthcheck runner

This page is a contributor SDK dump for `HealthcheckRunner`. It stays off the user nav.

If you author a service `healthcheck:` block, use the canonical fields: `kind` (`command`, `http`, `tcp`, or `none`), `command`, `url`, `port`, `intervalSeconds`, `timeoutSeconds`, `retries`, and `startPeriodSeconds`. Compose spellings `test`, `disable`, and duration strings (`interval`, `timeout`, `start_period`) also decode. Do not invent other keys.

`kind: command` runs inside the container. `tcp` and `http` probe from inside the per-app network. `none` disables the probe.

This is not a user how-to. For a running app, use [everyday commands](../cli/everyday-commands.mdx) and [lando doctor](./doctor-walkthrough.mdx).
