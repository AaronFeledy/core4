## Author service leaf certificates

A service's own leaf TLS certificate is configured with `certs:`. It is a separate surface from
`security.ca:`, which adds trusted certificate authorities; a service may declare both.

Issue a certificate from the active certificate authority:

```yaml
services:
  appserver:
    certs: true
```

Disable issuance for a service:

```yaml
services:
  appserver:
    certs: false
```

Supply a custom certificate path:

```yaml
services:
  appserver:
    certs: ./certs/appserver.crt
```

Supply an explicit certificate and key pair:

```yaml
services:
  appserver:
    certs:
      cert: ./certs/appserver.crt
      key: ./certs/appserver.key
```

The object form requires `cert` and accepts an optional `key`. Any other shape — a number, a list of
paths, a key without a certificate, or an unknown field beside `cert` and `key` — fails validation
with a `services.<name>.certs` correction before planning.
