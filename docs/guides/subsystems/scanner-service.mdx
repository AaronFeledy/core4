# Scanner service

This page is a contributor SDK dump for `UrlScanner`. It stays off the user nav.

The live scanner needs running containers and a provider socket. When it runs, `lando info --json` includes the discovered endpoints. Collision detection compares host ports across apps.

This is not a user how-to. Print URLs with `lando info`. See [everyday commands](../cli/everyday-commands.mdx).
