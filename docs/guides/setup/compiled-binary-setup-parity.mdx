# Setup compiled binary parity

## Setup and shellenv dispatch

Native dispatch, registry-completeness, and relocated compiled-binary smoke tests exercise setup and shellenv; this scenario documents the surface rather than rendering a transcript.

The top-level setup alias resolves to the canonical meta:setup command through the native dispatcher.

The canonical setup command remains available directly through the native command registry.

```sh
lando meta:setup
```

Unknown setup flags fail with a non-existent-flag diagnostic.

Shellenv parsing normalizes pwsh to the PowerShell snippet through the command input helper.

Invalid shell values fail before runtime bootstrap.

## Uninstall preview parity

Dry-run renders the non-mutating safety plan.

Without --yes, uninstall refuses destructive execution and renders the reviewed-plan reminder.

```sh
lando meta:uninstall
```

Unknown uninstall flags fail with a non-existent-flag diagnostic.

## Renderer boundary contract

Renderer-boundary lint is a source gate rather than a reader-visible CLI transcript.

Command results route through Renderer output stdout and diagnostics route through Renderer output stderr (`core/src/cli/renderer-boundary.ts`).

The gate rejects direct console/process writes under core/src and plugins outside the documented first-byte carve-outs.

This suite exercises the source entry through the native dispatcher; companion registry, machine-output, and relocated-binary suites prove the shared single-path contract (`core/test/cli/native-dispatch-unification.test.ts`).
