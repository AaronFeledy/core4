# Provider podman macos

## Macos podman desktop discovery

Podman Desktop socket discovery is exercised by plugins/provider-podman/test/capabilities.test.ts; the rendered live path requires a running Podman Desktop machine.

Podman Desktop default machine socket on macOS.

Override the machine name (e.g. rootful) without editing config.

```sh
LANDO_PODMAN_MACHINE=podman-machine-default-root
```

Socket precedence on macOS.

VM-mediated bind mounts are slow on macOS Podman Desktop.

## Macos podman desktop machine not running

Machine-not-running remediation is exercised by plugins/provider-podman/test/desktop.integration.test.ts; the rendered path requires Podman Desktop installed.

Tagged subclass of ProviderUnavailableError raised when the Podman Desktop machine socket is unreachable (`PodmanMachineNotRunningError`).

CLI remediation for a stopped Podman Desktop machine.

GUI remediation for the same condition.

## Macos live contract

The live SDK contract suite for Podman Desktop is gated by LANDO_TEST_PODMAN_DESKTOP_SOCKET and skipped by default.

Opt in to the live Podman Desktop contract suite.

```sh
LANDO_TEST_PODMAN_DESKTOP_SOCKET=$HOME/.local/share/containers/podman/machine/podman-machine-default/podman.sock
```

Test file containing the gated live scenario (`plugins/provider-podman/test/desktop.integration.test.ts`).
