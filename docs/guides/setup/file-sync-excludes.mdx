# Exclude paths from file sync

Every service skips `node_modules`, `vendor`, `.git`, and `tmp` by default. Those paths are not synced into the container.

## Add your own excludes

Add per-service patterns under `services.<name>.appMount.excludes` in your Landofile. Your patterns are appended after the defaults. Duplicates are removed.

If a path must stay synced even when it matches an exclude, add the same pattern to `services.<name>.appMount.includes`. Includes match whole patterns: `vendor` brings back all of `vendor/`, while `vendor/my-package` reopens nothing.

An authored `appMount` block needs `target`, the container path of the app mount. `/app` keeps the default. A different path moves the mount, and on Lando service types the working directory, `LANDO_APP_ROOT`, and `LANDO_PROJECT_MOUNT` follow it. Tomcat is the exception: it mounts the app at its `webroot`, so set `webroot` instead of `appMount.target` (a different `appMount.target` fails planning).

Set `appMount: false` on any service type to skip the app mount entirely. The container gets no app source, no `LANDO_APP_ROOT` or `LANDO_PROJECT_MOUNT`, and starts in the image's own working directory unless you set `workingDirectory`. Use it when the image bakes the code in, for example through `build:`. An authored `mounts:` entry whose target is the app mount path replaces Lando's app mount instead.

```yaml
services:
  app:
    type: "node:22"
    primary: true
    appMount:
      target: /app
      excludes:
        - dist
        - coverage
      includes:
        - vendor
```

## Framework presets

Some service types add their own excludes on top of the defaults. Python adds `__pycache__`. Ruby adds `.bundle`. Merged order is defaults, then service-type presets, then your excludes.

Excluded paths get an empty volume overlay so host files for that path are never read. Each service gets its own overlay, so two services never share an excluded directory. When a second service needs the same `vendor/` or `node_modules/`, include it on both.

## Verify

After you change excludes, rebuild so the mounts update:

```sh
lando rebuild
```
