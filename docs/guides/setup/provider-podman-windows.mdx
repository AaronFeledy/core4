# Use Podman Desktop on Windows

Alpha binaries are Linux x64 today. This page documents the Windows Podman provider path so the facts are here when that host is supported.

The default Podman Desktop machine named pipe on Windows is `npipe://./pipe/podman-machine-default`. Override the machine name, for example to target a rootful machine, without editing config:

```sh
LANDO_PODMAN_MACHINE=podman-machine-default-root
```

Bind mounts are WSL2-mediated on Windows Podman Desktop, so `bindMountPerformance` reports `slow`.

## Start the machine

If the Podman Desktop machine pipe is unreachable, Lando raises `PodmanMachineNotRunningError`, a tagged subclass of `ProviderUnavailableError`. Remediate from the CLI:

```sh
podman machine start podman-machine-default
```

Or from the GUI: open Podman Desktop on Windows and start the `podman-machine-default` machine.
