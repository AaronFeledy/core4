# Podman provider on Windows (Podman Desktop)

## Socket discovery

The default Podman Desktop machine named pipe on Windows is
`npipe://./pipe/podman-machine-default`. Override the machine name — for
example to target a rootful machine — without editing config:

```sh
LANDO_PODMAN_MACHINE=podman-machine-default-root
```

Bind mounts are WSL2-mediated on Windows Podman Desktop, so
`bindMountPerformance` reports `slow`.

## Machine not running

If the Podman Desktop machine pipe is unreachable, Lando raises
`PodmanMachineNotRunningError`, a tagged subclass of
`ProviderUnavailableError`. Remediate from the CLI:

```sh
podman machine start podman-machine-default
```

or from the GUI: open Podman Desktop on Windows and start the
`podman-machine-default` machine.

## Live contract suite

The live SDK contract suite for Podman Desktop is gated by
`LANDO_TEST_PODMAN_DESKTOP_SOCKET` and skipped by default. Opt in by
setting it:

```sh
LANDO_TEST_PODMAN_DESKTOP_SOCKET=npipe://./pipe/podman-machine-default
```

The gated scenario lives in
`plugins/provider-podman/test/desktop.integration.test.ts`.
