# Provider docker windows

## Windows named pipe discovery

Unit tests exercise Windows Docker Desktop discovery; the live HTTP API path still requires a real Docker Desktop install.

Named-pipe default when DOCKER_HOST is unset.

```sh
lando npipe://./pipe/docker_engine
```

Discovery precedence.

Windows Docker Desktop uses a VM, so bind mounts are slow.

## Windows live contract

Live Docker Engine HTTP API contract coverage requires Windows, Docker Desktop, and either LANDO_TEST_WINDOWS_DOCKER_SOCKET or DOCKER_HOST.

Preferred env var for a specific Docker Desktop endpoint.

```sh
LANDO_TEST_WINDOWS_DOCKER_SOCKET
```

Fallback env var when no override is set (`DOCKER_HOST`).

Shared SDK contract suite used by the live test (`@lando/sdk/test#runProviderContract`).
