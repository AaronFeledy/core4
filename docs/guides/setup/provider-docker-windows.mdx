# Use Docker Desktop on Windows

[Install Lando on Windows](../install/windows-installer.mdx) first. Docker Desktop is the fallback provider, not the default. You need working Docker Desktop first. With `lando` on PATH, run:

```sh
lando setup --provider=docker
```

After setup succeeds, run `lando doctor` and check that it reports Docker.

`--yes` consents to confirmation. It does not switch providers. See [What persists](./provider-selection.mdx#what-persists).

Windows Docker Desktop uses the named pipe `npipe://./pipe/docker_engine` when `DOCKER_HOST` is unset. Bind mounts are VM-mediated, so `bindMountPerformance` reports `slow`.

Setup fails with remediation if Docker Desktop is missing. It does not install Docker for you.

The default provider stays `lando`. Use Docker only after default setup fails or when you already run Docker Desktop. WSL is optional. See [Install Lando on WSL](../install/wsl.mdx) if you want the Linux binary instead.
