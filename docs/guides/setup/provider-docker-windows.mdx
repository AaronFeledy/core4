# Use Docker Desktop on Windows

Alpha binaries are Linux x64 today. There is no Windows `lando.exe` in Alpha. This page records the Docker Desktop provider path so the facts are here when that host is supported.

When a Windows binary ships, you need working Docker Desktop first. Then:

```sh
lando setup --provider=docker
```

`--yes` consents to confirmation. It does not switch providers. `LANDO_PROVIDER=docker` does not persist.

Windows Docker Desktop uses the named pipe `npipe://./pipe/docker_engine` when `DOCKER_HOST` is unset. Bind mounts are VM-mediated, so `bindMountPerformance` reports `slow`.

Setup fails with remediation if Docker Desktop is missing. It does not install Docker for you.

Until a Windows binary ships, run Lando inside WSL against Linux Docker or the managed `lando` provider. See [Install Lando on WSL](../install/wsl.mdx).
