# Run lando setup

Run `lando setup` yourself. Lando does not provision a provider in the background when you first run `lando start`.

First [install Lando and put it on PATH](../install/path-and-setup.mdx). Run setup in your terminal and follow the prompts. Choose the recommended Lando-managed runtime on supported hosts; it does not need system Docker or Podman. On an Intel Mac (`darwin-x64`), install and start Docker Desktop first, then choose Docker when setup asks. Setup does not install Docker for you.

## Use the defaults

```sh
lando setup
```

Then verify:

```sh
lando doctor
```

`--yes` consents to confirmation and privileged host changes. It does not switch providers. See [What persists](./provider-selection.mdx#what-persists).

Host prerequisites can block the managed runtime. If setup names one, fix it and rerun `lando setup`.

## Fall back to Docker

You need working system Docker.

```sh
lando setup --provider=docker
```

Later commands stay on Docker without repeating the flag. Setup does not install Docker or Podman for you. See [Pick a container provider](./provider-selection.mdx#what-persists) for what persists and how to switch back.

## Skip prompts

```sh
lando setup --no-interactive
lando setup --yes
lando setup --yes --provider=lando
```

`--no-interactive` skips prompts and keeps the same guided defaults. Combine `--yes` with an explicit `--provider` when you want a fully determined run.

See [Pick a container provider](./provider-selection.mdx). After setup, run [lando doctor](../subsystems/doctor-walkthrough.mdx).
