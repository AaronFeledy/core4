# Uninstall and purge

Uninstall is host-destructive once confirmed, so preview it first.
`uninstall --dry-run` prints the full owned, user-owned, skipped, and
manual-remediation plan without changing the system. Without `--yes`,
destructive execution is refused, and the same plan tells you to rerun
after review. `--yes` is required before any Lando-owned toolchain or data
target gets removed.

## Keep data vs. purge

```sh
# Removes Lando-owned toolchain targets while preserving user data roots,
# app data, global app state, and app-affecting caches
uninstall --yes --keep-data

# Opts into deliberate removal of Lando-owned data and cache roots,
# stops and destroys all running Lando apps, and removes their
# containers, networks, and volumes
uninstall --yes --purge
```

**Important:** `--purge` will stop and destroy all running Lando apps
(user apps, global services like the proxy and mailpit, and scratch apps)
and remove their Docker containers, networks, and volumes. If you want to
preserve any running apps, run `lando stop` or `lando destroy --volumes`
for specific apps before uninstall.

When `--purge` is used, Lando removes:
- All running app containers (including global proxy and mailpit)
- App-specific Docker networks
- App-specific Docker volumes
- User data root (`~/.local/share/lando` or `$LANDO_USER_DATA_ROOT`)
- User cache root (`~/.cache/lando` or `$LANDO_USER_CACHE_ROOT`)
- User config root (`~/.config/lando` or `$LANDO_USER_CONF_ROOT`)

A binary outside Lando's managed bin directory is never removed
automatically — the plan prints exact manual removal steps for it instead.

## Resumable reports

A failed confirmed uninstall writes a resumable report containing
completed, failed, skipped, and manual steps, at
`<userDataRoot>/uninstall/report.json` or
`<os-tmpdir>/lando-uninstall-*/lando-uninstall-report.json`. If a purge
failure already removed the data root, the report falls back to that
private tmpdir path instead. After remediation, rerun the same `keep-data`
or `purge` command to resume the remaining owned removals.
