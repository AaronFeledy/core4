# File sync mutagen

## Mutagen download on setup

Mutagen host CLI and per-platform agent downloads are exercised by plugins/file-sync-mutagen/test/provision.test.ts and core/test/downloader/acceptance.test.ts; the live network path requires the pinned CDN endpoints.

Mutagen downloads during setup on slow bind-mount providers.

```sh
lando setup
```

Mutagen host CLI installed under the per-user data root (`$LANDO_DATA_DIR/bin/mutagen`).

Per-target Mutagen agent binaries (linux-amd64, linux-arm64, linux-armv7) (`$LANDO_DATA_DIR/bin/mutagen-agents/`).

Pinned manifest provides the URL and SHA-256 for each host and agent variant (`plugins/file-sync-mutagen/mutagen-versions.json`).

Mutagen installs route through the shared provisionTool helper so checksum, containment, and idempotency match other host tools (`@lando/sdk/tool-provisioning`).

SHA-256 checksum verification (`sha256-checksum-verification`).

## Mutagen idempotent rerun

Idempotency is exercised by plugins/file-sync-mutagen/test/provision.test.ts; the marker file path is implementation-only.

Marker file stores the pinned version of the installed Mutagen binaries (`$LANDO_DATA_DIR/bin/.mutagen-installed-version`).

If the pinned version matches, lando setup reuses the existing binaries.

If the on-disk checksum mismatches, the file is re-downloaded and replaced.

## Mutagen skip flag

The --skip-file-sync flag is exercised through both source and compiled entries of the single native dispatcher.

Download Mutagen on the first accelerated app:start.

```sh
lando setup --skip-file-sync
```

## Mutagen doctor check

The file-sync doctor check is exercised by core/test/cli/commands/doctor.test.ts; the rendered NDJSON output requires a slow-bind-mount provider and an installed Mutagen binary.

Doctor reports the resolved Mutagen version on slow bind mounts.

```sh
lando doctor
```

Doctor check id added by the file-sync-mutagen plugin.

Native providers like Linux rootless Docker/Podman and OrbStack skip the file-sync check.

```text
bindMountPerformance: native
```

## Mutagen failure modes

Network, checksum, and unsupported-platform failure modes are exercised by plugins/file-sync-mutagen/test/provision.test.ts and core/test/downloader/acceptance.test.ts.

Network failures surface as FileSyncDownloadError; remediation cites connectivity and proxy or CA config.

Checksum mismatches surface as FileSyncChecksumError.

Tagged error raised on platforms outside Linux x64/arm64, macOS x64/arm64, and Windows x64 (`FileSyncUnsupportedPlatformError`).

## Mutagen system binary ignored

Lando always uses its own bundled Mutagen copy; the rendered path requires a system mutagen install on PATH which is environment-specific.

Lando uses its bundled Mutagen copy; the system PATH is ignored (`$LANDO_DATA_DIR/bin/mutagen`).

lando doctor warns about a conflicting system mutagen install.
