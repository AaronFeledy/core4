# Use Compose keys in a Landofile

Read the generated [Compose key matrix](../../reference/compose-key-matrix.mdx) before you paste Compose keys. Lando accepts a service-key vocabulary. It does not treat every Compose project file as a valid Landofile.

Each disposition describes what happens during planning:

- **normalized** resolves the input into a provider-neutral plan field.
- **preserved** accepts the input and carries it in the Compose plan extension. The matrix row detail determines whether provider capability checks apply. Service-level `x-*` extensions are inert and are not capability-gated.
- **rejected** fails closed with a tagged error and remediation rather than silently dropping intent.

Treat normalized and preserved entries as accepted only for the shapes the matrix documents. Use the matrix remediation for rejected input.

For a runnable example, continue with [Paste a Compose service into a Landofile](./compose-service-block.mdx).
