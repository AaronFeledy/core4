# Compose service block

Paste a Compose service definition under `services.<name>` and Lando
normalizes the keys it understands. `extra_hosts`, published `ports`, and
`depends_on` conditions all survive into the plan.

`configs:` is in that vocabulary too. Declare the file at the top level,
grant it onto a service with `source` / `target` / `mode`, and the bundled
providers mount it read-only. Handy for a drop-in `php.ini` without a
bind-mount workaround.

Use the disposition and remediation details in the [generated Compose key matrix](../../reference/compose-key-matrix.mdx) when porting additional Compose keys.

      <UseFixture name="compose-service-block-demo" />
      <Verify command="lando app:config --format=json" expect={{ stdout: { regex: "\"ok\":\\s*true" } }} />
    </Step>
    <Step name="cleanup-remediation">
      <Cleanup />
    </Step>
  </Scenario>
