# Paste a Compose service into a Landofile

Put `type: compose` on a service and keep the Compose keys the [generated Compose key matrix](../../reference/compose-key-matrix.mdx) accepts. `extra_hosts`, published `ports`, and `depends_on` conditions all survive into the plan.

`configs:` grants are realized as read-only binds. Declare the file at the top level, grant it onto a service with `source` / `target` / `mode`, and the bundled providers mount it. Handy for a drop-in `php.ini` without a bind-mount workaround.

```yaml
name: compose-service-block-demo
services:
  cache:
    type: compose
    image: valkey/valkey:8-alpine
  web:
    type: compose
    image: traefik/whoami:v1.10
    ports:
      - target: 80
        published: "8080"
        protocol: tcp
    depends_on:
      cache:
        condition: service_started
    extra_hosts:
      - "internal.test:127.0.0.1"
```
