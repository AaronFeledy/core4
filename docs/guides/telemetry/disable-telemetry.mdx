# Disable telemetry

Run this on the host to disable telemetry in your global config:

```sh
lando config telemetry off
```

This writes `telemetry.enabled=false` to the global config file. Future CLI runs resolve telemetry
from config when no higher-precedence environment or flag override is present.
Run `lando config telemetry status` afterward to check the effective state and
which source selected it.

## Disable it for one process

For a process-specific override, pass the environment variable below to the
Lando process instead of changing the config file. In a POSIX shell, place the
assignment immediately before the command you want to run; an assignment on its
own is not necessarily exported to child processes:

```sh
LANDO_CONFIG__TELEMETRY__ENABLED=0
```

The env overlay wins over `telemetry.enabled` in `config.yml`. Env beats config.

## Check the current status

```sh
lando config telemetry status
```

Reports whether telemetry is currently enabled, and which source selected the effective state:
`flag`, `env`, `config`, or `default`.
