# Disable telemetry

Turn telemetry off from the config file:

```sh
lando config telemetry off
```

This writes `telemetry.enabled=false` to the global config file. Future CLI runs resolve telemetry
from config when no higher-precedence env or flag override is present.

## Disable it for one process

To disable telemetry only for the current process, set an env override instead of touching the
config file:

```sh
LANDO_CONFIG__TELEMETRY__ENABLED=0
```

The env overlay wins over `telemetry.enabled` in `config.yml` — env beats config.

## Check the current status

```sh
lando config telemetry status
```

Reports whether telemetry is currently enabled, and which source selected the effective state:
`flag`, `env`, `config`, or `default`.
