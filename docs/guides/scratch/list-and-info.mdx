# List and info

## Scratch list columns

Lists every registered scratch app with its id, source, mode, creation time, and lifetime status.

```sh
lando apps:scratch:list
```

The scratch namespace alias reaches the same listing.

```sh
lando scratch:list
```

The default table renders one row per scratch app across these five columns.

The JSON renderer emits the same fields as a machine-readable array for scripting.

## Scratch list status

Lifetime status is derived from the local registry entry; classification needs no provider.

An attached scratch is a foreground app whose owning CLI process is still running.

A detached scratch (`--detach`) outlives the command that created it and survives until explicit destroy or gc.

An orphan is a foreground scratch whose owner process exited without cleanup, making it a reap candidate for apps:scratch:gc.

## Scratch info detail

Shows the same id / source / mode / created / status data plus the realized detail for one scratch app.

Each mount lists the owning service, the container target, the host path or volume source, the mount kind, and whether it is read-only.

Network membership reports the per-app bridge network and, when the app joined it, the shared cross-app network.

Endpoints are grouped by service and show each protocol, port, and optional name.

The JSON renderer emits the enriched detail object for scripting.
