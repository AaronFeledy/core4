# List scratch apps

`lando scratch:list` prints every registered scratch: id, source, isolation mode, created time, and status.

```sh
lando scratch:list
```

Need more than a roster? `lando scratch:info <id>` adds mounts, networks, and endpoints.

## List

```sh
lando scratch:list
lando scratch:list --format json
```

`lando scratch:list` is the alias of `apps:scratch:list`. The table columns are `ID`, `SOURCE`, `MODE`, `CREATED`, and `STATUS`. `--format json` emits the same fields as an array.

Source is `fork` or `recipe:<ref>`. Mode is `full`, `baked`, or `cwd`.

## Read status

Status comes from the local registry. No provider call.

| Status | Meaning |
| --- | --- |
| `attached` | Foreground scratch whose owning CLI process is still running. |
| `detached` | Started with `--detach` or kept with `--keep`. Lives until destroy or gc. |
| `orphan` | Foreground scratch whose owner exited without cleanup. `scratch:gc --prune` can reap it. |

## Inspect one scratch

```sh
lando scratch:info <id>
lando scratch:info <id> --format json
```

`lando scratch:info` is the alias of `apps:scratch:info`. The id is required.

Info repeats the list fields, then prints `root`, the per-app bridge (and the shared network when the scratch joined it), each mount (service, target, source, kind, read-only), and endpoints grouped by service.
