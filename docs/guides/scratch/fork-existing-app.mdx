# Fork existing app

## Scratch fork command

Starts a scratch fork from the Landofile discovered in the current directory.

The scratch namespace alias reaches the same fork mode behavior.

Returns after the provider apply starts the fork resources instead of keeping an attached command session (`--detach`).

Running fork mode outside a directory with a resolvable Landofile fails before any scratch app is created.

## Scratch fork identity

Every fork receives a generated scratch identity so the forked plan does not reuse the source app slug or provider resource names.

The scratch id is generated from --name, then the source Landofile name, then app as a fallback (`scratch-<base>-<6hex>`).

The fork plan uses the scratch id for id, name, and slug.

Service DNS aliases derive from the scratch slug instead of the source slug (`web.<scratch-id>.internal`).

The source Landofile object is not rewritten when the fork plan is derived (`untouched`).

## Scratch fork provider resources

Fork mode is intended to let the source app and scratch fork run at the same time with separate provider resources.

Provider containers are named from the scratch slug, so source and fork containers do not collide (`separate`).

The fork gets its own per-app bridge network instead of joining the source app network (`lando-<scratch-id>`).

Service volumes and file-sync names are derived from the scratch app name when the plan is rebuilt.

Starting the fork does not stop or rename the current-directory source app (`simultaneous`).

## Scratch fork shared root

The first fork mode implementation shares the current project directory by design and leaves content-copy isolation for a later command surface.

The fork plan keeps the source app root so code edits are visible to both apps.

No source files are copied into the scratch cache when --fork starts.

Only the scratch instance metadata directories are materialized under the user cache root.

Isolation applies to containers, networks, DNS, and derived volume names, not to the mounted content.
