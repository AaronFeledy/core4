# Run the Astro recipe

```sh
lando init --recipe astro --name=astro-demo --yes
lando start
```

`--yes` skips prompts. Defaults are Node lts and no database. First start builds `web`. If host ports 80 or 443 are already taken, `lando info` URLs may use fallback ports such as `:8080` and `:8443`.

## See what the recipe writes

Init writes `.lando.yml` only. Put an Astro app in after start.

| Piece | What you get |
| --- | --- |
| `web` | `node:lts` (or `node:22` when you pass `--answer=node=22`), port `4321`, `ASTRO_TELEMETRY_DISABLED=1` |
| `database` | omitted by default; `postgres` with `--answer=database=postgres`; `mariadb` with `--answer=database=mariadb` |
| Tooling | `lando astro` (`npx astro`) and `lando npm` on `web` |

Routes use `{{ app.name }}.{{ proxy.defaultDomain }}` on HTTP and HTTPS. Pick a database and `web` waits on that service.

## Scaffold Astro, then run it

`create-astro` wants a clean directory, and `.lando.yml` is already there. Scaffold into a subdirectory, then move the app up and keep `.lando.yml`:

```sh
lando exec web -- npx --yes create-astro@4.13.2 webapp -- \
  --template minimal \
  --install \
  --no-git \
  --typescript strict \
  --yes \
  --skip-houston \
  --no-ai
```

Move the contents of `webapp/` into the app root. Leave `.lando.yml` in place. If `node_modules` already exists at the root, move the scaffold files first, remove the empty root `node_modules` if needed, then run:

```sh
lando npm install
```

Confirm tooling:

```sh
lando astro --version
lando astro --help
lando npm --version
```

Serve through the proxy with an all-interfaces bind. Pass your app hostname to Astro so Vite accepts the Traefik `Host` header:

```sh
lando astro dev --host 0.0.0.0 --port 3000 --allowed-hosts astro-demo.lndo.site
```

Open the URL `lando info` prints. Prefer Node 22 with Postgres at init?

```sh
lando init --recipe astro --name=astro-pg --yes \
  --answer=node=22 \
  --answer=database=postgres
```

MariaDB instead:

```sh
lando init --recipe astro --name=astro-maria --yes \
  --answer=database=mariadb
```

## Talk to Postgres

When you pick `database=postgres`, the app network hostname is `database`:

| Setting | Value |
| --- | --- |
| Host | `database` |
| Port | `5432` |
| Database | app name (here `astro-pg`) |
| User | `lando` |
| Password | generated when omitted; read it from `lando info` |

Ping from the database service:

```sh
lando exec database -- psql -U lando -d astro-pg -c 'SELECT version();'
```

Swap `astro-pg` for your app name. Point your Astro content source or ORM at host `database`. Do not hardcode the password in committed app code.

## Destroy without surprises

```sh
lando destroy -y
```

That removes containers and networks. Volumes stay unless you pass `--volumes` or `--purge`.
