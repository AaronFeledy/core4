# Run the Next.js recipe

```sh
lando init --recipe nextjs --name=nextjs-demo --yes
lando start
```

`--yes` skips prompts. Defaults are Node lts, Postgres, and `NEXTAUTH_PROVIDER: none`. First start builds `web` and `database`. If host ports 80 or 443 are already taken, `lando info` URLs may use fallback ports such as `:8080` and `:8443`.

## See what the recipe writes

Init writes `.lando.yml` only. Put a Next.js app in after start.

| Piece | What you get |
| --- | --- |
| `web` | `node:lts` (or `node:22` when you pass `--answer=node=22`), port `3000`, `NEXTAUTH_PROVIDER` set from the auth answer |
| `database` | `type: postgres` by default; `mariadb` with `--answer=database=mariadb`; omitted with `--answer=database=none` |
| Tooling | `lando next` (`npx next`) and `lando npm` on `web` |

Routes use `{{ app.name }}.{{ proxy.defaultDomain }}` on HTTP and HTTPS. Auth answers (`none`, `nextauth`, `clerk`) only set the `NEXTAUTH_PROVIDER` env hint. Install and configure the helper yourself.

## Scaffold Next.js, then run it

`create-next-app` wants a clean directory, and `.lando.yml` is already there. Scaffold into a subdirectory, then move the app up and keep `.lando.yml`:

```sh
lando exec web -- npx --yes create-next-app@15.5.2 webapp
```

Move the contents of `webapp/` into the app root. Leave `.lando.yml` in place. Then confirm tooling:

```sh
lando next --version
lando next --help
lando npm --version
```

Serve through the proxy with an all-interfaces bind:

```sh
lando next dev --hostname 0.0.0.0 --port 3000
```

Open the URL `lando info` prints. Prefer Node 22, no database, or NextAuth at init?

```sh
lando init --recipe nextjs --name=nextjs-alt --yes \
  --answer=node=22 \
  --answer=database=none \
  --answer=auth=nextauth
```

## Talk to Postgres

Default recipe Postgres uses the app network hostname `database`:

| Setting | Value |
| --- | --- |
| Host | `database` |
| Port | `5432` |
| Database | app name (here `nextjs-demo`) |
| User | `lando` |
| Password | generated when omitted; read it from `lando info` |

Ping from the database service:

```sh
lando exec database -- psql -U lando -d nextjs-demo -c 'SELECT version();'
```

Swap `nextjs-demo` for your app name. Point your Next.js DB URL at host `database`. Do not hardcode the password in committed app code.

## Destroy without surprises

```sh
lando destroy -y
```

That removes containers and networks. Volumes stay unless you pass `--volumes` or `--purge`.
