# Run Drupal multisite on one appserver

The `drupal` recipe scaffolds one PHP appserver and one database. There is no recipe knob for multisite. You add routes, per-site `settings.php`, and Drush URI aliases on top of the generated Landofile.

Every site still shares the same appserver, PHP version, webroot, and database service. Multisite splits the Drupal document root and config, not the containers.

## Route one hostname per site

Add one `routes:` entry per hostname. Every hostname hits the same appserver.

```yaml
services:
  appserver:
    type: php:8.3
    webroot: /app/web
    allowOverride: true
    routes:
      - hostname: site1.lndo.site
      - hostname: site2.lndo.site
```

Confirm the list with `lando app:config --format=json` before you start the app.

## Write per-site settings.php

Point Drupal's `sites/sites.php` at your Lando hostnames:

```php
<?php
$sites['site1.lndo.site'] = 'site1';
$sites['site2.lndo.site'] = 'site2';
```

Then `web/sites/site1/settings.php` connects to the shared `database` service. Usually only the database name changes:

```php
<?php
$databases['default']['default'] = [
  'driver' => 'mysql',
  'host' => 'database',
  'database' => 'site1',
  'username' => 'drupal',
  'password' => 'drupal',
  'prefix' => '',
];
```

The stock `mariadb` service provisions one schema named after the app. Create extra schemas before each site's installer:

```sh
lando mysql -e "CREATE DATABASE site1"
lando mysql -e "CREATE DATABASE site2"
```

Use the matching client if your engine is not MariaDB.

## Add Drush URI aliases

Drush needs `--uri` because every site bootstraps on the same appserver. Bake the URI into one tooling task per site:

```yaml
tooling:
  drush-site1:
    service: appserver
    cmd:
      - vendor/bin/drush
      - --uri=https://site1.lndo.site
  drush-site2:
    service: appserver
    cmd:
      - vendor/bin/drush
      - --uri=https://site2.lndo.site
```

Then you stop retyping `--uri`:

```sh
lando drush-site1 status
lando drush-site2 status
```

## Install each site

Start the app. Lando starts Traefik and issues certificates for each route. Then install:

```sh
lando drush-site1 site-install standard --db-url=mysql://drupal:drupal@database/site1 -y
lando drush-site2 site-install standard --db-url=mysql://drupal:drupal@database/site2 -y
```

Open each hostname:

- `https://site1.lndo.site`
- `https://site2.lndo.site`

## Know the shared-stack limits

One appserver means one PHP version, one `webroot`, one `allowOverride`, and one set of PHP extensions. You cannot run one site on a different PHP version than its neighbors.

The database is shared too. Per-site schemas live on the same `mariadb` instance, so a schema-level backup of one site still hits the server every other site depends on.
