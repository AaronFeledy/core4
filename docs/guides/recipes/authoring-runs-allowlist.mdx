# Author a recipe runs allowlist

Declare the canonical command ids a recipe may execute from `ctx.run`,
`postInit` command actions, or `choicesFrom` with `runs`. It sits next to
`requires`, `prompts`, `files`, and `postInit` in the recipe manifest:

```yaml
runs:
  - git
  - composer
```

When `runs` is present, only ids in that array may execute; every other id
fails before a child process starts.
