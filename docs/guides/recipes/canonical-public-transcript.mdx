## Read a Landofile through the library runtime

Embedding hosts can read app files through the core `FileSystem` service under a test runtime, without shelling out to the CLI.

```ts
import { Effect } from "effect";
import { FileSystem } from "@lando/core";
import { makeTestRuntime } from "@lando/core/testing";

const runtime = makeTestRuntime({
  files: {
    "/app/.lando.yml": "name: canonical-library\nservices:\n  appserver:\n    type: node\n",
  },
});

const landofile = await Effect.runPromise(
  Effect.gen(function* () {
    const files = yield* FileSystem;
    return yield* files.readText("/app/.lando.yml");
  }).pipe(Effect.provide(runtime.layer)),
);
console.log(landofile);
```
