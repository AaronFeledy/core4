# Write a programmatic recipe

`Recipe`, `RecipeContext`, `RecipeFactory`, and the `defineRecipe` identity
helper are published from `@lando/sdk`. A `recipe.ts` default-exports a
static `Recipe` object, the same shape `recipe.yml` decodes to:

```ts
import { type Recipe, defineRecipe } from "@lando/sdk";

export default defineRecipe({ id, title, description, version, prompts, files, postInit });
```

`recipe.ts` loads through Bun's native TypeScript loader; no `tsc` step
runs at recipe-load time.
