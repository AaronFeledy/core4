# Author a recipe fetch allowlist

Declare the URL globs a recipe may contact from `ctx.fetch` with
`fetchAllowlist`. It sits next to `requires`, `runs`, `prompts`, `files`,
and `postInit` in the recipe manifest:

```yaml
fetchAllowlist:
  - https://api.example.com/**
```

`*` matches within a single path segment; `**` matches across path
segments. So `https://api.example.com/**` matches any path, while
`https://registry.lando.dev/recipes/*` matches only one segment.
