# Run the LEMP recipe

```sh
lando init --recipe lemp --name=lemp-demo --yes
cd lemp-demo
lando start
```

The named init creates `lemp-demo/` and writes only `.lando.yml` there. Change into it before app commands. `--yes` keeps PHP 8.4. Nginx fronts PHP-FPM on `appserver`, and MariaDB is up after start. Drop an `index.php` in the project root, then open the URL `lando info` prints.

If something else owns 80 or 443, Lando picks the next free port (usually `:8080` / `:8443`) and `lando info` shows it.

## See what the recipe writes

| Piece | What you get |
| --- | --- |
| `web` | `nginx`, `backend: appserver`, webroot `/app`, HTTP and HTTPS routes, not primary |
| `appserver` | `php:8.4`, `framework: none`, `via: fpm`, webroot `/app`, primary, depends on `database` |
| `database` | `type: mariadb` (MariaDB 11.4) |
| Tooling | `lando composer` and `lando php` on `appserver`, plus `lando mariadb` from the database service |

Routes use `{{ app.name }}.{{ proxy.defaultDomain }}` on HTTP and HTTPS. Pass `--answer=php=8.2` when you want PHP 8.2 instead.

`web` owns the public URL. `appserver` runs PHP-FPM only, so `lando info` lists no HTTP endpoints on it. That split is the point of LEMP: nginx takes the requests, FPM runs the PHP.

## Serve a simple PHP page

Put `index.php` in the app root (`/app`):

```php
<?php
header('Content-Type: text/plain; charset=utf-8');
echo 'lemp-ok php=' . PHP_VERSION . ' sapi=' . PHP_SAPI . "\n";
```

Then:

```sh
lando info
lando open --print
```

`lando open --print` shows the app HTTPS URL (port included when the proxy fell back). Open that URL or curl it. A working FPM path reports `sapi=fpm-fcgi`, not `cli`.

## Run Composer, PHP, and MariaDB

```sh
lando composer --version
lando php -v
lando mariadb -e 'SELECT 1 AS ok;'
```

`lando composer` and `lando php` run on `appserver`. `lando mariadb` opens the client on `database` with the app credentials already set.

## Connect PHP to MariaDB

| Setting | Value |
| --- | --- |
| Host | `database` |
| Database | app name (here `lemp-demo`) |
| User | `lando` |
| Password | `lando` |
| Port | `3306` |

Use the service key `database`, not `127.0.0.1` or `localhost`. Root password is generated; `lando info` redacts it, and you do not need it for the app user.

PDO example that hits MariaDB from PHP-FPM:

```php
<?php
header('Content-Type: text/plain; charset=utf-8');
echo 'lemp-ok php=' . PHP_VERSION . ' sapi=' . PHP_SAPI . "\n";
$pdo = new PDO('mysql:host=database;dbname=lemp-demo', 'lando', 'lando');
$row = $pdo->query('SELECT 1 AS ok')->fetch(PDO::FETCH_ASSOC);
echo 'pdo-ok=' . ($row['ok'] ?? 'missing') . "\n";
```

The stock PHP image already has `pdo_mysql` and `mysqli`.

## Import and export the database

```sh
lando db:export dump.sql.gz
lando db:import dump.sql.gz --yes
lando mariadb -e 'SELECT 1 AS ok;'
```

The recipe has one database service, so neither command needs `--service`. A `.gz` name gzips on export and gunzips on import. Importing into a non-empty database asks first; `--yes` skips the prompt.
