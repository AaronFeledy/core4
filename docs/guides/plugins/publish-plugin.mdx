# Publish a plugin

Use a publish dry run to check the package before release. Run it from the
plugin root: it rebuilds a stale `dist/`, runs tests, and lists the artifact
without contacting a registry. A live registry publish is not a supported
how-to in this Beta.

```sh
lando meta:plugin:publish --dry-run
```

Confirm that the command exits successfully and lists the artifact you intend
to release. This verifies the dry run, not a registry publication.

If the rebuild or retest that runs first exits nonzero, publication stops with
`PluginPublishValidationError` before anything is published. Fix the build or
test, or run [test or build directly](./test-and-build-plugin.mdx) to see the
failure on its own. If the `bun publish` child itself exits nonzero, Lando
exits with that code and, under `--format=json`, reports it as
`result.exitCode` with the child's output in the envelope. The registry token
Lando hands the child is redacted everywhere it could appear. Details are in
[Script Lando with JSON](../scripting-with-json.mdx#capture-bun-backed-commands).

## Flags that work

```sh
lando meta:plugin:publish --dry-run --tag latest
lando meta:plugin:publish --dry-run --no-test
```

`--tag` defaults to `latest`. Empty or whitespace tags fail.

`--no-test` skips the retest. A stale `dist/package.json` still triggers `meta:plugin:build`.

## Where publish credentials come from

A publish without `--dry-run` reads its registry token from your npm user config
(`~/.npmrc`, or the file named by `NPM_CONFIG_USERCONFIG`), the same file
[private plugin installs](./install-from-npm.mdx#install-from-a-private-registry)
use. Lando has no separate login command and stores no credentials.

```ini
@acme:registry=https://npm.example.com/
//npm.example.com/:_authToken=${NPM_TOKEN}
```

The registry is `--registry`, then `package.json`'s `publishConfig.registry`,
then the scope's registry or default registry from your npm configuration, then
the public npm registry. Lando passes the matching token to Bun through
`BUN_AUTH_TOKEN`, never as a command argument. When no token matches,
`PluginPublishAuthError` names the npm config file and the token key to add.

## Verify

```sh
lando meta:plugin:publish --dry-run
```

The command should exit 0.
