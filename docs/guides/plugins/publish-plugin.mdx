# Publish a plugin

Validate the built artifact and list its package contents without
performing a network publish:

```sh
lando meta:plugin:publish --dry-run
```

Dry-run prints the dist package contents (for example
`dist/index.d.ts`, `dist/index.js`, `dist/package.json`), the planned
registry and tag, the validation result, then exits 0.
