# Link a local plugin

Run `lando meta:plugin:link` from your plugin checkout to validate it and create
a symlink in your user plugin root. Keep the checkout at that location while
using the link.

```sh
lando meta:plugin:link
```

With no argument, the command uses your current directory. Pass a path to link
a checkout elsewhere:

```sh
lando meta:plugin:link ../lando-plugin-demo
```

After linking, check that `<userDataRoot>/plugins/<name>` points to your checkout,
where `<name>` is the plugin manifest's name.

## Fix a rejected manifest

If linking fails with `PluginManifestError`, read the issue paths and reasons
below the message, then correct those fields in `package.json`. Unknown keys are
rejected. The manifest is the `landoPlugin` object when present, otherwise the
whole `package.json`.

For scripts or editor integrations, request structured diagnostics:

```sh
lando meta:plugin:link ../lando-plugin-demo --format=json
```

The failure envelope carries `error.issues`, each with a `path` array and a
`message`, plus `error.remediation`. An empty path means the manifest root.

For example, an extra `unexpected` key in `landoPlugin` is rejected with the
issue path `["unexpected"]`. Remove the key from `package.json`, then rerun
the link command. Lando validates the manifest before creating the link.

## What it writes

The link target is `<userDataRoot>/plugins/<manifest.name>`. State also lands in:

- `<userDataRoot>/plugins/.lando-linked.json`
- `<userDataRoot>/plugins/registry.json` with `source: "linked"`

An existing non-linked install of the same name is left alone. Unlink or remove it first. `file:` on `plugin:add` is `NotImplementedError` in this Beta. Link is the local path.

Also trust the absolute checkout if you need postinstall or authoring-root checks:

```sh
lando meta:plugin:trust-authoring-root /absolute/path/to/plugin
```

Replace `/absolute/path/to/plugin` with the checkout's absolute path. Relative
paths are rejected.

## Unlink

```sh
lando meta:plugin:unlink @acme/lando-plugin-demo
```

Only linked names unlink. A registry install is `lando plugin:remove`.

## Verify

```sh
lando meta:plugin:link
```

Then confirm `<userDataRoot>/plugins/<name>` is a symlink to the checkout.
