# Trust plugins by name

Trust applies to one exact plugin name. Organization wildcards are not
supported. Review the current trusted names before adding or revoking one:

```sh
lando plugin:trust list
```

## What works today

The first command below trusts a package name; the second revokes that trust.
Choose the action you need. Trust permits plugin code to run on your host.

```sh
lando plugin:trust @lando/plugin-php
lando plugin:trust revoke @lando/plugin-php
```

Authorize a local checkout with an absolute path.

Replace `/absolute/path/to/plugin` with your checkout's absolute path. Relative
paths are rejected.

```sh
lando meta:plugin:trust-authoring-root /absolute/path/to/plugin
```

See [Manage plugin trust](./trust-management.mdx).
