# Trust plugin postinstall

Lando runs a package's `postinstall` only when the package is trusted. Trust
allows code to run on your host, so use the following commands only for a
package you have decided to authorize.

```sh
lando plugin:trust @lando/plugin-php
lando plugin:add @lando/plugin-php --trust
```

An untrusted package can be unpacked on disk without its `postinstall` script
running. The presence of package files does not prove that the script ran.

## Trust a name

```sh
lando plugin:trust @lando/plugin-php
lando plugin:trust list
```

Trusted names persist in `<userConfRoot>/plugin-trust.yml`. Organization
wildcards are not supported.

`--trust` and `-y` on `plugin:add` also persist that name. Non-interactive add without `--trust` fails with InteractionRequiredError when the package has no `scripts.postinstall` (the same prompt path as explicit `--trust`). If the package has `scripts.postinstall` and you omit `--trust`, the tarball still lands and the script is skipped (`trustSource: untrusted`).

## Trust a checkout

Replace `/absolute/path/to/plugin` with the checkout's absolute path. Relative
paths are not accepted.

```sh
lando meta:plugin:trust-authoring-root /absolute/path/to/plugin
```

## When postinstall runs

`plugin:add` unpacks without running scripts. A trusted name with a non-empty `scripts.postinstall` then runs `bun install` in that package directory with the Bun that Lando ships.

A name that is not trusted skips that step. A trusted script that exits nonzero
fails the add with `PluginPackageOperationError`, operation `postinstall`, and
the script's exit code; the CLI exits `1`. In your terminal the script's output
streams as it runs, and the error points you back to it. Under `--format=json`
the output is collected into the envelope instead. The plugin isn't activated,
but the trust you granted stays in place, so fix the package's script or
dependencies and run `lando plugin:add` again. See
[Script Lando with JSON](../scripting-with-json.mdx#capture-bun-backed-commands)
for the envelope and error fields.

## Verify

```sh
lando plugin:trust list
lando plugin:trust @lando/plugin-php
```

Then add with `--trust` only for packages you want to run as host code.
