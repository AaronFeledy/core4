# Trust postinstall

## Trust plugin postinstall

Persist a trusted npm plugin name in `<userConfRoot>`/plugin-trust.yml and invalidate the plugin command cache.

```sh
lando plugin:trust @lando/plugin-php
```

The command prints the exact trusted plugin name after the trust store write succeeds.

```sh
trusted-plugin: @lando/plugin-php
```

Trust a resolved absolute plugin authoring root for local development workflows.

```sh
lando meta:plugin:trust-authoring-root /absolute/path/to/plugin
```

Relative paths are rejected; absolute paths are resolved before persistence.

```sh
trusted-authoring-root: /absolute/path/to/plugin
```

Untrusted plugin installs never execute package postinstall scripts by default, including non-interactive installs.

Trusted postinstall execution routes through the recursion-guarded BunSelfRunner install child and publishes pre/post bun-self-exec events.
