# List trusted plugins

```sh
lando plugin:trust list
```

That prints the non-expiring trusted plugin names and trusted authoring roots from `<userConfRoot>/plugin-trust.yml`. Output includes `trusted-plugins` and `trusted-authoring-roots` sections, using `[]` for empty sections.
