# Manage plugin trust

Print the non-expiring trusted plugin names and trusted authoring roots from
`<userConfRoot>/plugin-trust.yml`:

```sh
lando plugin:trust list
```

List output includes `trusted-plugins` and `trusted-authoring-roots`
sections, using `[]` for empty sections.
