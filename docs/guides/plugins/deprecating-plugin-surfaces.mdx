# Deprecate plugin surfaces

Attach a `DeprecationNotice` to the plugin manifest root to deprecate a whole
plugin. Every deprecation field uses the canonical `DeprecationNotice`
contract: `since`, `removeIn`, `severity`, `replacement`, `note`, `docsUrl`,
`ticket`.
