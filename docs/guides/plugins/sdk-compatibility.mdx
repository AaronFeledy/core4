# Declare SDK compatibility

Every Lando v4 plugin manifest must declare a `requires` map pinning the
`@lando/core` major version it targets. The map lives alongside `name`,
`version`, and `api` on the plugin manifest the SDK decodes before any
plugin module loads:

```json
{
  "requires": { "@lando/core": "^4.0.0" }
}
```

A scaffolded plugin `package.json` ships this already set to the supported
core range:

```json
{
  "name": "@acme/lando-plugin-foo",
  "api": 4,
  "requires": { "@lando/core": "^4.0.0" }
}
```
