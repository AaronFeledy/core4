# Test and build a plugin

Run these from the plugin root (or a nested cwd). Lando walks up to the nearest plugin `package.json`.

```sh
lando meta:plugin:test
lando meta:plugin:build
```

Dash, then Bun flags. Everything after `--` is none of Lando's business.

## Test

```sh
lando meta:plugin:test test/plugin.test.ts -- --bail
```

Paths before `--` are test files. Flags after `--` go to Bun `test` unchanged. The command validates the plugin manifest first.

A non-zero Bun exit is a non-zero Lando exit.

## Build

```sh
lando meta:plugin:build
```

Build reads `package.json` `exports`, compiles those entrypoints to `./dist` as ESM for Bun, emits declaration files, then writes `dist/package.json`. Mixed source trees that the builder cannot place under one `rootDir` fail closed.

## Verify

```sh
lando meta:plugin:test
lando meta:plugin:build
```

A passing pair leaves `dist/` with the built entrypoints.
