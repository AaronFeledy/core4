# Test and build a plugin

Run the current plugin's Bun test suite from the detected plugin root,
forwarding post-dash Bun arguments unchanged:

```sh
lando meta:plugin:test test/plugin.test.ts -- --bail
```

The command emits plugin-test lifecycle events around the `BunSelfRunner`
test execution: `cli-meta:plugin:test-start`, `pre-bun-self-exec`,
`post-bun-self-exec`, `cli-meta:plugin:test-complete`.
