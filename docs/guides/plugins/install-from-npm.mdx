# Install a plugin from npm

Resolve npm metadata, download the published tarball, validate the plugin
manifest, and trust the plugin for the current session:

```sh
lando plugin:add @lando/plugin-foo --trust
```

Pin an exact version with an `@version` suffix:

```sh
lando plugin:add @lando/plugin-foo@1.2.3 --trust
```

Installed plugin packages are published under the per-user plugin root by
name and resolved version, at
`<userDataRoot>/plugins/@lando/plugin-foo/1.2.3/`.
