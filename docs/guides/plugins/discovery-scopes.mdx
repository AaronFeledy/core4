# Plugin discovery scopes

Lando discovers plugins from three sources:

- **System** — the bundled plugin set compiled into Lando.
- **User** — discovered from the managed per-user plugin registry written by
  `lando plugin:add`, at `<userDataRoot>/plugins/registry.json`.
- **App** — discovered from the current app root's local plugin registry, at
  `<appRoot>/.lando/plugins/registry.json`.

Discovered plugin contribution module paths (`globalServices`, `downloaders`,
`httpClients`, `interactionServices`, `remoteSources`, `datasets`,
`snapshotStores`) are normalized from their package root before the registry
publishes them to runtime services.
