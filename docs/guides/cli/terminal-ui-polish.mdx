# Terminal UI polish

This page is a contributor design-token dump for the bundled `lando` renderer. It stays off the user nav.

Everyday CLI work lives in [everyday commands](./everyday-commands.mdx). Do not treat status chips, OpenTUI, or desktop-notification policy as something you configure from a Landofile.

The default TTY path can draw a compact task tree. `plain`, `json`, non-TTY, and CI stay undecorated. A missing native binding never fails the command. The process falls back to line input.

If you are changing renderer goldens, start from the contributing visual-QA page, not this dump.
