# Power off every app

`lando poweroff` stops every Lando-managed app on the host, not just this
one.

Warning: this command reaches beyond the current app. Run it only when you
mean to stop everything. It removes scratch apps and their disposable data
unless you pass `--keep-scratch`.

## Scope flags

Skip the shared global app with `--keep-global`, so host-wide services such
as the proxy keep running. Skip scratch apps with `--keep-scratch`, so
disposable throwaway apps stay up while every other app stops.

Poweroff does not prompt for confirmation. `-y`/`--yes` is accepted, but is
not required for scripts.

User apps stop first, followed by scratch cleanup, then the global app.
Lando stops the managed runtime service only after all targeted apps stop.
If an app cannot stop, the command fails with that app's id and remediation
instead of reporting it as powered off. The runtime stays available so you
can resolve the failure and retry.

`lando poweroff` is a top-level alias for `lando apps:poweroff`. Both
invoke the same command. It works from any directory; you don't need to be
inside an app root to run it.
