# Read service logs

```sh
lando logs --service appserver
```

That prints a snapshot for the service, merging console output with any declared file sources. File-source lines carry their source id (`appserver stderr [myapp-error]: line`). Console lines omit a source label (`appserver stdout: line`).

Declare extra in-container log files on the service that owns them:

```yaml
services:
  myapp:
    logs:
      - path: /var/log/myapp/error.log
        stream: stderr
        label: myapp error log
```

A user-declared source needs a `path`. You can also set `id`, `label`, `stream`, and timestamp behavior. The implicit container stdout/stderr source is always available. Use `--source console` when you want only engine logs.

Lando-built images can redirect daemon log files through stdout/stderr. Bring-your-own images and logs that cannot redirect are followed by the active runtime provider. You do not run `tail -F` yourself.

## Filter and follow

Restrict output to one declared source id, or to `console`:

```sh
lando logs --service appserver --source myapp-error
```

`--follow` backfills the source tail, then streams new lines until you interrupt:

```sh
lando logs --service appserver --source myapp-error --follow
```

`--tail` applies per source, not as one total across merged sources:

```sh
lando logs --service appserver --tail 50
```

`--since` accepts durations such as `30s`, `15m`, `2h`, `7d`, or an RFC3339 timestamp:

```sh
lando logs --service appserver --since 15m
```

## When a source is missing

A provider that cannot stream service logs fails before planning with a tagged capability error and a fix. Follow sources from container files need the `serviceLogSources` capability. Redirect sources still work without it because they flow through the console stream.

A required follow source fails up front when the provider cannot follow service files. A non-required unavailable follow source is marked unavailable and skipped. An undeclared `--source` fails and lists the known source ids, including `console`.

Without `--follow`, a file source emits a bounded snapshot and reaches EOF. Followers survive common log rotation (rename+create and copytruncate) and keep per-source order. Interrupting `lando logs` releases every follower. Lines are redacted once before they reach the CLI.
