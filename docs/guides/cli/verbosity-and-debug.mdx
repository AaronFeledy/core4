# See more CLI output

`lando version --debug` turns on debug logs. If you did not pick a renderer, it also flips the default `lando` renderer to `verbose`.

```sh
lando version --debug
```

`--debug` is `--log-level=debug` plus that default-to-verbose flip. Pass `--renderer=lando` when you want the TUI. Pass `--renderer=json` when you want the JSON envelope on stdout.

## Pick a renderer

| Mode | What you get |
| --- | --- |
| `lando` (default) | Bundled TTY task tree and summaries. |
| `plain` | One human line per renderable event on stdout. No tree, no spinners. |
| `json` | Structured `{_tag:"event", ...}` lines on stderr. The command result still prints on stdout as a JSON envelope. |
| `verbose` | The human line plus the full event payload for every event. This is the debug dump, not the task tree. |

Set the mode three ways. First match wins:

1. `--renderer=verbose`
2. `LANDO_RENDERER=verbose`
3. `renderer: verbose` in global config

The default is `lando`.

`--format=json` changes the command result shape. It does not switch the event stream. `--renderer=json` forces the result format to JSON and also emits JSON events on stderr.

```sh
lando info --format=json
lando info --renderer=json
```

An unknown mode fails with `RendererSelectionError`.

## Turn on `--debug`

`--debug` sets the log level to `debug`. When the renderer still came from the default, Lando flips it to `verbose`. `--renderer=lando --debug` keeps the TUI. `--renderer=json --debug` keeps the envelope on stdout.

Set the log level three ways. First match wins:

1. `--log-level=debug` or `--debug`
2. `LANDO_LOG_LEVEL=debug` or `LANDO_DEBUG=1` (`true` and `yes` also count)
3. `logLevel: debug` in global config

The default log level is `none`. The CLI stays quiet until you ask.

For scripts and agents, prefer `--format=json` or `--renderer=json` and read `ok`, `error._tag`, and `remediation`.
