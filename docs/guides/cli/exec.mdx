# Run commands inside a service

`lando exec` runs a one-off command inside a running service. Everything after `--` is the exact argv handed to the service. The command spec is non-strict, so it parses no flags of its own past that point.

```sh
lando exec -- echo hello world
lando exec --service app -- echo hello world
lando exec --user www-data -- whoami
lando exec --cwd /srv/app -- pwd
```

Open a shell with `lando ssh` or `lando shell --service <name>`.

## Exit codes

`app:exec` sets its own command exit code to the executed command's `exitCode`. A non-zero result is mirrored onto the CLI process, so `lando exec` propagates the target command's failure to the shell.

## Machine-readable output

`--format json` emits one JSON object per stdout/stderr chunk, then exactly one result frame:

```sh
lando exec --format json -- <command>
```

Each non-empty stdout chunk becomes one stdout frame tagged with the target service. A non-empty stderr chunk becomes one stderr frame the same way. An empty stream emits no frame for that stream. The stream always terminates with exactly one result frame carrying the app, service, command, exit code, stdout, and stderr.
