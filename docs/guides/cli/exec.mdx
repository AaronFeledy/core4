# Run commands inside a service

`lando exec` runs a one-off command inside a running service, or opens a
shell in one with `lando ssh`. Everything after `--` is the exact argv
handed to the service; the command spec is non-strict, so it parses no
flags of its own past that point.

## Exit codes

`app:exec` sets its own command exit code to the executed command's
`exitCode`, not a fixed success value. A non-zero result exit code is
mirrored onto the CLI process exit code (`process.exitCode = result.exitCode`),
so `lando exec` propagates the target command's failure to the shell.

## Machine-readable output

`app:exec` is a streaming command: `--format json` emits one NDJSON
`StreamFrame` per stdout/stderr chunk, terminated by exactly one result
frame:

```sh
lando exec --format json -- <command>
```

Each non-empty stdout chunk from the executed command becomes one stdout
`StreamFrame` tagged with the target service:

```json
{ "_tag": "stdout", "service": "app", "chunk": "..." }
```

A non-empty stderr chunk becomes one stderr `StreamFrame` the same way; an
empty stream emits no frame for that stream:

```json
{ "_tag": "stderr", "service": "app", "chunk": "..." }
```

The stream always terminates with exactly one result frame carrying the
app, service, command, exit code, stdout, and stderr:

```json
{ "ok": true, "result": { "exitCode": 0, "stdout": "...", "stderr": "..." } }
```
