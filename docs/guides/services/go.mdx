# Go

Add a Go service to your app by declaring `type: go:1.23` for the primary
service — Go has no bare `type: go` alias, so pin a version. Lando currently
supports `go:1.22` and `go:1.23`, and derives the default image
(`golang:1.23` for `go:1.23`) from the version you pin. Your repository is
bind-mounted read-write at `/app`, which is also the working directory:

```yaml
name: go-demo
services:
  web:
    type: "go:1.23"
```

## Primary service

A service named `web` is the primary service by default, so tooling commands
target it without an explicit `service` field. To make a differently-named
service the default target, set `primary: true` on it:

```yaml
services:
  api:
    type: "go:1.23"
    primary: true
```

## Run the app

The default keep-alive command holds the container open so you can build and
run your program via tooling or `lando exec`:

```sh
# Compile the project inside the running Go service
lando exec web -- go build -o /tmp/app .

# Or run it directly
lando exec web -- go run .
```

Bind your HTTP server to the default port `8080` so it's reachable through
the proxy at the app URL.

## Pin a version

Pin a different supported Go minor version, or set `image:` to use a custom
Go base image:

```yaml
services:
  web:
    type: go:1.22
```

```yaml
services:
  web:
    type: "go:1.23"
    image: golang:1.23-bookworm
```
