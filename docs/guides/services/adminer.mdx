# Browse your database in Adminer

Add `type: adminer` to browse and edit your local app's database in a browser. Run the commands below from the app directory on your host.

## Add Adminer next to Postgres

Save this as `.lando.yml` in an empty directory. In an existing app, add only the `adminer` service under `services:`.

```yaml
name: adminer-demo
services:
  db:
    type: postgres
  adminer:
    type: adminer
```

```sh
lando start
lando info
```

Open the HTTPS URL listed for `adminer`. Adminer signs you into the only database in the app with its configured credentials, so there is no login form to fill in. The database page shows your tables once you've created or imported them. If the browser warns about the certificate, see [Trust local HTTPS certificates](../subsystems/certificates-mkcert.mdx).

If you see `password authentication failed`, follow [Recover when credentials don't match](./postgres.mdx#recover-when-credentials-dont-match) to bring the running Postgres password back in sync with your Landofile.

## Use MariaDB or MySQL

Use the same `adminer` service next to `type: mariadb` or `type: mysql`. After `lando start`, open the Adminer URL from `lando info` as before.

```yaml
name: adminer-mariadb
services:
  db:
    type: mariadb
  adminer:
    type: adminer
```

## Choose among several databases

```yaml
name: adminer-multiple
services:
  reports:
    type: postgres
  store:
    type: mariadb
  adminer:
    type: adminer
```

Run `lando start` and open the Adminer URL from `lando info`. Choose `reports (PostgreSQL)` or `store (MariaDB)` from **Server**, then click **Login**. Adminer uses the credentials and default database for the service you chose. Adminer doesn't list `mssql` services yet.

## Open and edit a SQLite file

Declare `sqlite.path` on the service that owns the file. Adminer lists the owning service and path when there are several database choices.

```yaml
name: adminer-sqlite
services:
  appserver:
    type: "php:8.3"
    primary: true
    sqlite:
      path: data/site.sqlite
  adminer:
    type: adminer
```

If your app hasn't created the file yet, save this as `notes.sql` in the app directory:

```sql
CREATE TABLE notes (id INTEGER PRIMARY KEY, body TEXT);
INSERT INTO notes (body) VALUES ('hello from lando');
```

```sh
lando start
lando db:import notes.sql --yes
lando info
```

Open Adminer, select `notes`, and check that the imported row appears. On Linux with the default provider, the `podman` provider, or a local rootful Docker engine, Adminer saves your edits as your host user, the same way your app's own writes land. Elsewhere, run `lando info`, read the `project user` row for `adminer`, and see [Who owns your app files](./file-ownership.mdx).

## Remove it

Remove the service from your Landofile and apply the change:

```sh
lando app:config:unset services.adminer
lando start
```

`lando info` no longer lists the Adminer URL. Your database service and its data remain.
