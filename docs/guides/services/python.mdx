# Python

Add a Python service to your app by declaring `type: python:3.12` for the
primary service — Python has no bare `type: python` alias, so pin a
version. Lando currently supports `python:3.12`, and the default image is
`python:3.12-slim`. Your repository is bind-mounted read-write at `/app`,
which is also the working directory:

```yaml
name: python-demo
services:
  app:
    type: "python:3.12"
    primary: true
```

## Run the app

The default keep-alive command holds the container open so you can install
dependencies and run your app via tooling:

```sh
# Declare a pip tooling alias to install dependencies inside the service
lando pip install -r requirements.txt

# Run a Django/Flask server with lando exec; bind to 0.0.0.0 so the proxy can reach it
lando exec app -- python manage.py runserver 0.0.0.0:8000
```

## Pin a version

Set `image:` to use the full (non-slim) or an alternate Python base image
when the default `python:3.12-slim` isn't what you want — slim lacks build
tools that some packages need:

```yaml
services:
  app:
    type: "python:3.12"
    image: python:3.12
```
