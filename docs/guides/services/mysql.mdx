# MySQL

Add a MySQL database to your app by declaring `type: mysql` in your
services block. Lando pulls `mysql:8.0` by default and listens on the
standard TCP port `3306`:

```yaml
name: mysql-demo
services:
  db:
    type: mysql
```

Start it and Lando wires the database into your app's network:

## Connection details

Other services in your app connect using the service name as the hostname —
here that's `db`. The defaults:

| Setting | Value |
| --- | --- |
| Host | `db` |
| Database | the app name (`mysql-demo`); override with `database:` under `services.db` |
| User | `lando` |
| Password | `lando` |
| Root password | derived per app; read it from `lando info` |

From inside the app network the connection URL is:

```
mysql://lando:lando@db:3306/mysql-demo
```

## CLI access

Declare a tooling alias targeting the `db` service to open the `mysql`
client:

```sh
lando mysql
```

A common companion is a `db-import` tooling alias that pipes a SQL file into
the client:

```sh
lando db-import dump.sql
```

## Pin a version

Use `image:` to pin a specific MySQL version when the default `mysql:8.0`
isn't what you want:

```yaml
services:
  db:
    type: mysql
    image: mysql:8.4
```
