# Add MySQL

Put `type: mysql` in your services block. Lando pulls `mysql:8.0` and listens on `3306`:

```yaml
name: mysql-demo
services:
  db:
    type: mysql
```

Start it. Lando puts the database on the app network:

## Connect from another service

Other services use the service name as the hostname. Here that's `db`. Defaults:

| Setting | Value |
| --- | --- |
| Host | `db` |
| Database | the app name (`mysql-demo`); override with `database:` under `services.db` |
| User | `lando` |
| Password | `lando` |
| Root password | derived per app; read it from `lando info` |

From inside the app network the connection URL is:

```
mysql://lando:lando@db:3306/mysql-demo
```

## Open the client

Add a tooling alias on `db` to open the `mysql` client:

```sh
lando mysql
```

There is no core `db-import`. Pipe a dump into `mysql` with `lando exec`, or add your own tooling alias. See [Import a SQL dump](../tooling/import-a-database.mdx).

## Pin a version

Set `image:` when `mysql:8.0` isn't the version you want:

```yaml
services:
  db:
    type: mysql
    image: mysql:8.4
```
