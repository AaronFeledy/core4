# Add RabbitMQ

Put `type: rabbitmq` in your services block. That shorthand is an alias for the RabbitMQ 4 image line:

```yaml
name: rabbitmq-demo
services:
  queue:
    type: rabbitmq
```

## Pick a version

Use `rabbitmq:4` when you want the default major version written out. Choose
`rabbitmq:3` for an app that still needs RabbitMQ 3:

```yaml
services:
  queue:
    type: rabbitmq:3
```

## Connect

Other services connect to `queue` on the standard AMQP port, `5672`. The
default username and password are both `lando`, so the local connection URL is:

```
amqp://lando:lando@queue:5672
```

RabbitMQ also exposes its management UI on port `15672`. Lando gives that UI a
default route, so check `lando info` for the app URL instead of guessing a host
port. Sign in with `lando` and `lando`.

## Keep queue data

RabbitMQ stores its data in `/var/lib/rabbitmq`. The service mounts persistent
storage there by default, which keeps queues and messages across ordinary
restarts. Plain `lando destroy` keeps the data volume. Adding `--volumes` or
`--purge` removes it and the queues and messages it contains.

RabbitMQ's default node name is `rabbit@<hostname>`, and its data directory
depends on that name. Lando derives a stable hostname from
`<app slug>-<service>`, so recreating the container keeps the same node name
as long as the app slug and service name stay the same.

Existing containers keep their old hostname until they are recreated. That
first recreation changes the node name; renaming the app or service can also
change it. RabbitMQ may then start with a new, empty data directory even though
the old data is still on the volume. If you need to keep existing messages,
plan the migration before recreating the container. Follow RabbitMQ's
[backup and restore guidance](https://www.rabbitmq.com/docs/backup), which
requires the same node name when restoring a data directory.

## Manage the broker

The service adds `rabbitmqctl` and `rabbitmqadmin` tooling aliases. Run them
from your host when you need to inspect queues, users, or broker state:

```sh
lando rabbitmqctl list_queues
lando rabbitmqadmin list exchanges
```
