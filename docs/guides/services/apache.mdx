# Add Apache

Put `type: apache` in your services block. Lando pulls `httpd:2.4-alpine` and listens on `80`:

```yaml
name: apache-demo
services:
  web:
    type: apache
```

Your repository is mounted at `/app`, which is also set as `APACHE_DOCUMENT_ROOT`. Start it. Lando wires the service into the proxy:

## Open the URL

The proxy derives an HTTPS hostname from the service's HTTP endpoint without a `proxy:` block. You'll get something like `web.<app>.lndo.site`.

Override the served directory by setting `APACHE_DOCUMENT_ROOT` under
`services.web.environment`:

```yaml
services:
  web:
    type: apache
    environment:
      APACHE_DOCUMENT_ROOT: /app/public
```

## Pin a version

Set `image:` when `httpd:2.4-alpine` isn't the version you want. For example, a Debian-based image:

```yaml
services:
  web:
    type: apache
    image: httpd:2.4
```
