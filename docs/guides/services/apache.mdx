# Add Apache

Put `type: apache` in your services block. Lando pulls `httpd:2.4-alpine` and listens on `80`:

```yaml
name: apache-demo
services:
  web:
    type: apache
```

Your repository is mounted at `/app`, which is also the default `webroot` and `APACHE_DOCUMENT_ROOT`. Start it. Lando wires the service into the proxy:

## Open the URL

The proxy derives an HTTPS hostname from the service's HTTP endpoint without a `proxy:` block. You'll get something like `web.<app>.lndo.site`.

Set `webroot:` when Apache should serve a subdirectory. Lando writes that path into Apache's generated config and exposes it as `LANDO_WEBROOT` and `APACHE_DOCUMENT_ROOT`:

```yaml
services:
  web:
    type: apache
    webroot: /app/public
```

An explicit `environment.APACHE_DOCUMENT_ROOT` still wins for custom setups. If you replace `command:` or `entrypoint:`, your launcher owns the Apache config too.

## Pin a version

Set `image:` when `httpd:2.4-alpine` isn't the version you want. For example, a Debian-based image:

```yaml
services:
  web:
    type: apache
    image: httpd:2.4
```
