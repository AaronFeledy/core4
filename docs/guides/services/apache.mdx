# Apache

Add an Apache web server to your app by declaring `type: apache` in your
services block. Lando pulls `httpd:2.4-alpine` by default and listens on the
standard HTTP port `80`:

```yaml
name: apache-demo
services:
  web:
    type: apache
```

Your repository is mounted at `/app`, which is also set as
`APACHE_DOCUMENT_ROOT`. Start it and Lando wires the service into the proxy:

## Routing

The proxy derives an HTTPS hostname from the service's HTTP endpoint without
needing a `proxy:` block — you'll get something like `web.<app>.lndo.site`.

Override the served directory by setting `APACHE_DOCUMENT_ROOT` under
`services.web.environment`:

```yaml
services:
  web:
    type: apache
    environment:
      APACHE_DOCUMENT_ROOT: /app/public
```

## Pin a version

Use `image:` to pin a specific Apache httpd version when the default
`httpd:2.4-alpine` isn't what you want. For example, a Debian-based image:

```yaml
services:
  web:
    type: apache
    image: httpd:2.4
```
