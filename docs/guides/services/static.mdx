# Serve a static site

Put `type: static` in your services block. That defaults to the nginx variant. Lando pulls `nginx:1.26-alpine` and listens on `80`. The document root defaults to `/app`, and the app source is mounted read-only. The server can't mutate your repository:

```yaml
name: static-demo
services:
  web:
    type: static
    root: dist
tooling:
  curl:
    service: web
    cmd:
      - sh
      - -c
      - 'path=${1:-/}; curl -sf -- "http://localhost:80/${path}"'
      - curl
```

## Serve a subdirectory

Setting `root: dist` (as the fixture above does) serves the build output
directory and sets `LANDO_WEBROOT=/app/dist` inside the container.

## Serve with Caddy

Prefer Caddy? Set `type: static:caddy`. Its default image is `caddy:2-alpine`:

```yaml
services:
  web:
    type: static:caddy
```

## Pin a version

Set `image:` to pin a specific nginx or Caddy version:

```yaml
services:
  web:
    type: static
    image: nginx:1.27-alpine
```

```yaml
services:
  web:
    type: static:caddy
    image: caddy:2.8-alpine
```
