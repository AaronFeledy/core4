# Static

Serve a static site by declaring `type: static` in your services block,
which defaults to the nginx variant. Lando pulls `nginx:1.26-alpine` by
default and listens on the standard HTTP port `80`. The document root
defaults to `/app`, the app mount root, and the app source is mounted
read-only — the server can't mutate your repository:

```yaml
name: static-demo
services:
  web:
    type: static
    root: dist
tooling:
  curl:
    service: web
    cmd:
      - sh
      - -c
      - 'path=${1:-/}; curl -sf -- "http://localhost:80/${path}"'
      - curl
```

## Serve a subdirectory

Setting `root: dist` (as the fixture above does) serves the build output
directory and sets `LANDO_WEBROOT=/app/dist` inside the container.

## Caddy variant

The static service also supports a Caddy variant for users who prefer Caddy
over nginx. Set `type: static:caddy` to serve via Caddy instead; its default
image is `caddy:2-alpine`:

```yaml
services:
  web:
    type: static:caddy
```

## Pin a version

Use `image:` to pin a specific nginx or Caddy version instead of the
default image:

```yaml
services:
  web:
    type: static
    image: nginx:1.27-alpine
```

```yaml
services:
  web:
    type: static:caddy
    image: caddy:2.8-alpine
```
