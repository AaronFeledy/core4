# Valkey

Add Valkey to your app by declaring `type: valkey` in your services block.
Lando pulls `valkey/valkey:8` by default and listens on the standard port
`6379`:

```yaml
name: valkey-demo
services:
  cache:
    type: valkey
tooling:
  valkey-cli:
    service: cache
    cmd:
      - valkey-cli
```

## Connection endpoints

`lando info` advertises both a `valkey://` endpoint (primary) and a
`redis://` alias, so new and existing client libraries connect without code
changes:

```
valkey://localhost:6379
redis://localhost:6379
```

## CLI access

The fixture above declares `valkey-cli` as an app tooling alias. Ping the
cache to verify it's reachable:

```sh
lando valkey-cli ping
```

Store and read a key:

```sh
lando valkey-cli set hello world
lando valkey-cli get hello
```

## Pin a version

Use `image:` to pin a specific Valkey major version when the default image
isn't what you want:

```yaml
services:
  cache:
    type: valkey
    image: valkey/valkey:7
```
