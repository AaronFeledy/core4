# Add Valkey

Put `type: valkey` in your services block. Lando pulls `valkey/valkey:8` and listens on `6379`:

```yaml
name: valkey-demo
services:
  cache:
    type: valkey
tooling:
  valkey-cli:
    service: cache
    cmd:
      - valkey-cli
```

## Connect from another service

`lando info` advertises both a `valkey://` endpoint (primary) and a `redis://` alias, so new and existing client libraries connect without code changes:

```
valkey://localhost:6379
redis://localhost:6379
```

## Open the client

The fixture above declares `valkey-cli` as an app tooling alias. Ping the cache to verify it's reachable:

```sh
lando valkey-cli ping
```

Store and read a key:

```sh
lando valkey-cli set hello world
lando valkey-cli get hello
```

## Pin a version

Set `image:` when the default image isn't the version you want:

```yaml
services:
  cache:
    type: valkey
    image: valkey/valkey:7
```
