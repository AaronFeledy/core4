# Add SQL Server

Put `type: mssql` in your services block. That shorthand is the 2022 image. It listens on `1433`, keeps data in `/var/opt/mssql`, and ships `sqlcmd` tooling:

```yaml
name: mssql-demo
services:
  database:
    type: mssql
```

## Pick a version

Use `mssql:2022` when you want the default major written out. Choose `mssql:2019` for the previous line:

```yaml
services:
  database:
    type: mssql:2019
```

## Set credentials

Set `creds:` when you need explicit values. `rootPassword` becomes `SA_PASSWORD` inside the container. The image also gets `ACCEPT_EULA=Y` and `MSSQL_PID=Developer`. Read the resolved password from `lando info` instead of guessing it.

## Plan on amd64

Upstream SQL Server images are amd64-only. On a non-amd64 host the type fails at plan time unless the provider declares architecture emulation. Use an amd64 host or a provider with architecture emulation. This is a capability check, not a container start failure.

```sh
lando sqlcmd -Q "SELECT @@VERSION"
```
