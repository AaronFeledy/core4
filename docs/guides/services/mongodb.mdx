# MongoDB

Add MongoDB to your app by declaring `type: mongodb` in your services block.
Lando pulls `mongo:7` by default and listens on port `27017`:

```yaml
name: mongodb-demo
services:
  db:
    type: mongodb
```

The default root credentials are `lando` / `lando`, set via
`MONGO_INITDB_ROOT_USERNAME` and `MONGO_INITDB_ROOT_PASSWORD`.

## Verify it's healthy

`mongosh` requires a running MongoDB container. Run it after start:

```sh
lando mongosh --eval "db.runCommand('ping')"
```

## Pin a version

Set `image:` to use `mongo:6` or `mongo:8` instead of the default `mongo:7`:

```yaml
services:
  db:
    type: mongodb
    image: mongo:6
```

```yaml
services:
  db:
    type: mongodb
    image: mongo:8
```
