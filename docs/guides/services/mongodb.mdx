# Add MongoDB

Put `type: mongodb` in your services block. Lando pulls `mongo:7` and listens on `27017`:

```yaml
name: mongodb-demo
services:
  db:
    type: mongodb
```

Set `creds:` when you want explicit values. Defaults are `lando` / `lando` via `MONGO_INITDB_ROOT_USERNAME` and `MONGO_INITDB_ROOT_PASSWORD`.

```yaml
services:
  db:
    type: mongodb
    creds:
      user: lando
      password: lando
```

## Check that it's healthy

The `mongodb` type ships the `mongosh` client task. After start:

```sh
lando mongosh --eval "db.runCommand('ping')"
```

## Use your own mongod.conf

Set `config.server` to an app-relative file when you need to tune the server:

```yaml
services:
  db:
    type: mongodb
    config:
      server: ./config/mongod.conf
```

Lando mounts that file read-only at `/etc/lando/mongod.conf` and starts the server with `--config /etc/lando/mongod.conf`. It has to be a regular file, not a directory.

The path has to stay inside the app root. Absolute paths, paths that climb out of the app root, and symlinks that point outside it are rejected when Lando plans the app, before anything starts.

If you also set `command:` or `entrypoint:` on the service, yours wins. Lando won't append `--config` to a command you wrote yourself, so pass it in your own command if you still want the file loaded.

## Change the port

Set `port:` to move the daemon's listener, healthcheck, endpoint, and Lando's own clients together:

```yaml
services:
  db:
    type: mongodb
    port: 27018
```

Lando starts `mongod` with `--port 27018`, including when `config.server` is mounted. Other services connect to `db:27018`. The service exposes `LANDO_DB_PORT=27018`; `lando mongosh` and `lando db:*` commands use the planned port too. MongoDB has no daemon-native port environment variable.

If you author `command:` or `entrypoint:`, you own the daemon's flags. Include `--port 27018` in your own launcher; Lando won't append it for you.

Apply the change with `lando rebuild`, then ping through the generated client:

```sh
lando mongosh --eval 'db.runCommand({ping:1})'
```

## Pin a version

Set `image:` to use `mongo:6` or `mongo:8` instead of `mongo:7`:

```yaml
services:
  db:
    type: mongodb
    image: mongo:6
```

```yaml
services:
  db:
    type: mongodb
    image: mongo:8
```
