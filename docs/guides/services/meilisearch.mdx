# Add Meilisearch

Put `type: meilisearch` in your services block. That resolves to the `meilisearch:1` image line. Lando pulls `getmeili/meilisearch:v1.11` and listens on `7700`:

```yaml
name: meilisearch-demo
services:
  search:
    type: meilisearch
```

## Check health and set a key

Expose a tooling alias that curls the health endpoint after start:

```sh
lando meili /health
```

A healthy Meilisearch reports a JSON body with `status: available`.

Without a master key, Meilisearch runs in development mode with auth disabled. That's fine locally, not for production. Set `MEILI_MASTER_KEY` under `services.search.environment` to require an API key:

```yaml
services:
  search:
    type: meilisearch
    environment:
      MEILI_MASTER_KEY: your-key-here
```

## Pin a version

Set `image:` when the default v1.11 isn't the version you want:

```yaml
services:
  search:
    type: meilisearch
    image: getmeili/meilisearch:v1.10
```
