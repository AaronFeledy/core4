# Meilisearch

Add Meilisearch to your app by declaring `type: meilisearch` in your
services block, which resolves to the `meilisearch:1` image line. Lando
pulls `getmeili/meilisearch:v1.11` by default and listens on port `7700`:

```yaml
name: meilisearch-demo
services:
  search:
    type: meilisearch
```

## Health check and auth

Expose a tooling alias that curls the health endpoint after start:

```sh
lando meili /health
```

A healthy Meilisearch reports a JSON body with `status: available`.

Without a master key, Meilisearch runs in development mode with auth
disabled — that's fine locally but not for production. Set
`MEILI_MASTER_KEY` under `services.search.environment` to require an API
key:

```yaml
services:
  search:
    type: meilisearch
    environment:
      MEILI_MASTER_KEY: your-key-here
```

## Pin a version

Use `image:` to pin a specific Meilisearch version when the default v1.11
isn't what you want:

```yaml
services:
  search:
    type: meilisearch
    image: getmeili/meilisearch:v1.10
```
