# Memcached

Add Memcached to your app by declaring `type: memcached` in your services
block. Lando pulls `memcached:1.6` by default and listens on the standard
port `11211`:

```yaml
name: memcached-demo
services:
  cache:
    type: memcached
tooling:
  memcached-tool:
    service: cache
    cmd:
      - sh
      - -c
      - printf "%s\r\n" "$*" | nc -q 1 127.0.0.1 11211
      - memcached-tool
```

## Inspect runtime stats

The fixture above declares `memcached-tool` as an app tooling alias. Run it
after start to inspect the live Memcached service:

```sh
lando memcached-tool stats
```

## Pin a version

Use `image:` to pin a compatible Memcached Docker image when the default
image isn't sufficient — for example, a Debian-based image:

```yaml
services:
  cache:
    type: memcached
    image: memcached:1.6-bookworm
```
