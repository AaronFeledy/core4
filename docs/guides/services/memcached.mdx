# Add Memcached

Add `type: memcached` under `services` in `.lando.yml`. Lando pulls `memcached:1.6` and listens on `11211`:

```yaml
name: memcached-demo
services:
  cache:
    type: memcached
tooling:
  memcached-tool:
    service: cache
    cmd:
      - sh
      - -c
      - printf "%s\r\n" "$*" | nc -q 1 127.0.0.1 11211
      - memcached-tool
```

## Inspect runtime stats

The Landofile above declares `memcached-tool` as an app tooling alias. Run it after start to inspect the live Memcached service:

```sh
lando memcached-tool stats
```

## Change the port

Set `port:` to move the daemon's listener, healthcheck, and endpoint together:

```yaml
services:
  cache:
    type: memcached
    port: 11212
```

Lando starts `memcached` with `-p 11212`. Other services connect to
`cache:11212`. Memcached has no daemon-native port environment variable.

If you author `command:`, include `-p 11212` yourself; Lando never appends it
to a command you wrote. An authored `entrypoint:` still receives Lando's
`memcached` command, port included. Update any tooling that hardcodes `11211`
when you move the port.
If startup fails with an authored command, Lando includes a hint naming
`-p 11212`.

Apply the change with `lando rebuild`.

## Pin a version

Set `image:` when the default image isn't enough. For example, a Debian-based image:

```yaml
services:
  cache:
    type: memcached
    image: memcached:1.6-bookworm
```
