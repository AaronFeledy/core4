# Add Memcached

Add `type: memcached` under `services` in `.lando.yml`. Lando pulls `memcached:1.6` and listens on `11211`:

```yaml
name: memcached-demo
services:
  cache:
    type: memcached
tooling:
  memcached-tool:
    service: cache
    cmd:
      - sh
      - -c
      - printf "%s\r\n" "$*" | nc -q 1 127.0.0.1 11211
      - memcached-tool
```

## Inspect runtime stats

The Landofile above declares `memcached-tool` as an app tooling alias. Run it after start to inspect the live Memcached service:

```sh
lando memcached-tool stats
```

## Configure the listener

Set `port:` to change Memcached's listener and healthcheck together. An authored `command:` owns the listener configuration; pass the planned port with `-p`. An authored `entrypoint:` still receives Lando's command with `-p` and must execute the supplied command and arguments. If Memcached never becomes ready, `lando start` reports which ports it's actually listening on, so a launcher that ignores `port:` is easy to spot. See [Inspect a failed start](./wait-for-your-app.mdx#inspect-a-failed-start).

## Pin a version

Set `image:` when the default image isn't enough. For example, a Debian-based image:

```yaml
services:
  cache:
    type: memcached
    image: memcached:1.6-bookworm
```
