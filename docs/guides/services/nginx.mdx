# nginx

Add an nginx web server to your app by declaring `type: nginx` in your
services block. Lando pulls `nginx:1.26-alpine` by default and listens on
the standard HTTP port `80`. Your repository is mounted at `/app` and served
as the document root:

```yaml
name: nginx-demo
services:
  web:
    type: nginx
```

## Routing

Routes are derived from service endpoints — the proxy auto-derives an HTTPS
hostname from the nginx service's HTTP endpoint, something like
`web.<app>.lndo.site`. You only need a `proxy:` block to customize
hostnames.

## Pair with PHP

nginx is commonly paired with a `php-fpm` service: nginx serves static
files and proxies dynamic requests to the app service over the per-app
network.

```yaml
services:
  web:
    type: nginx
  app:
    type: "php:8.3"
```

## Pin a version

Use `image:` to pin a specific nginx version when the default
`nginx:1.26-alpine` isn't what you want:

```yaml
services:
  web:
    type: nginx
    image: nginx:1.27-alpine
```
