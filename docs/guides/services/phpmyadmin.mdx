# Add phpMyAdmin

Put `type: phpmyadmin` in your services block. In an app with one MySQL or MariaDB service, that is enough. Lando points the UI at that database and gives it a default hostname route:

```yaml
name: phpmyadmin-demo
services:
  db:
    type: mysql
  pma:
    type: phpmyadmin
```

## Pick a version

`phpmyadmin` is an alias for `phpmyadmin:latest`. Pin `phpmyadmin:5` when
you want that major written out:

```yaml
services:
  pma:
    type: phpmyadmin:5
```

## Point at several databases

phpMyAdmin auto-discovers every `mysql` and `mariadb` service in the app
and lists them in the UI. It does not wire PostgreSQL or SQL Server.

## Override discovered hosts

Set `hosts:` when auto-discovery is not what you want. A string or a list
replaces discovery entirely:

```yaml
services:
  pma:
    type: phpmyadmin
    hosts:
      - db
      - db-other
```

The service listens on `80`, gets a default hostname route, and turns on
`lando.certs`. Set `certs: false` if you do not want a leaf certificate.

A `hosts:` entry that names a sibling `mysql` or `mariadb` service reuses that sibling's `creds:`. A host that is not a sibling needs explicit `creds:` on the phpMyAdmin service:

```yaml
services:
  pma:
    type: phpmyadmin
    hosts:
      - remote-db
    creds:
      user: lando
      password: lando
```
