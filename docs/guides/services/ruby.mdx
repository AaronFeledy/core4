# Ruby

Add a Ruby service to your app by declaring `type: ruby:3.3` for the
primary service — Ruby has no bare `type: ruby` alias, so pin a version.
Lando currently supports `ruby:3.3`, and the default image is
`ruby:3.3-slim`. Your repository is bind-mounted read-write at `/app`,
which is also the working directory:

```yaml
name: ruby-demo
services:
  app:
    type: "ruby:3.3"
    primary: true
```

## Run the app

The default keep-alive command holds the container open so you can install
gems and run your app via tooling:

```sh
# Declare a bundle tooling alias to install gems inside the service
lando bundle install

# Run a Rails server with lando exec; bind to 0.0.0.0 so the proxy can reach it
lando exec app -- bundle exec rails server -b 0.0.0.0
```

## Pin a version

Set `image:` to use the full (non-slim) or an alternate Ruby base image when
the default `ruby:3.3-slim` isn't what you want — slim lacks build tools
that some gems need:

```yaml
services:
  app:
    type: "ruby:3.3"
    image: ruby:3.3
```
