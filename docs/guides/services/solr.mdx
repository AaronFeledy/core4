# Solr

Add Solr to your app by declaring `type: solr` in your services block,
which resolves to the `solr:9` image. Lando pulls it by default and
listens on port `8983`:

```yaml
name: solr-demo
services:
  search:
    type: solr
```

## Precreate cores

List cores under `services.search` to have Solr precreate them on boot,
before the foreground server starts:

```yaml
services:
  search:
    type: solr
    cores: [default, products]
```

`precreate-core` runs for each declared core before `solr-foreground`, so
every core exists before the server accepts queries.

## Admin API

Expose a tooling alias that curls the Solr admin API after start to confirm
the HTTP surface is reachable:

```sh
lando solr-cli /solr/admin/info/system
```

That's the same endpoint the built-in healthcheck curls
(`curl -sf http://localhost:8983/solr/admin/info/system`) before Lando
reports `post-start`.

## Pin a version

Use `image:` to pin a specific Solr image when the default `solr:9` isn't
what you want:

```yaml
services:
  search:
    type: solr
    image: solr:9.6
```
