# Add PostgreSQL

Put `type: postgres` in your services block. Lando pulls `postgres:16` and listens on `5432`:

```yaml
name: postgres-demo
services:
  db:
    type: postgres
```

Start it. Lando puts the database on the app network:

## Connect from another service

Other services use the service name as the hostname. Here that's `db`. Defaults:

| Setting | Value |
| --- | --- |
| Host | `db` |
| Database | the app name (`postgres-demo`); override with `database:` under `services.db` |
| User | `lando` |
| Password | derived per app (`lando-<hash>`) |

The password is derived per app, so read the exact value from `lando info`. Don't hardcode it. From inside the app network the connection URL is:

```
postgresql://lando:<password>@db:5432/postgres-demo
```

## Open the client

Add a tooling alias on `db` to open `psql`:

```sh
lando psql
```

A common companion is `db-import`, which pipes a SQL file into `psql`:

```sh
lando db-import dump.sql
```

## Pin a version

Set `image:` when `postgres:16` isn't the version you want:

```yaml
services:
  db:
    type: postgres
    image: postgres:15
```
