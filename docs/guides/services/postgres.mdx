# PostgreSQL

Add a PostgreSQL database to your app by declaring `type: postgres` in your
services block. Lando pulls `postgres:16` by default and listens on the
standard port `5432`:

```yaml
name: postgres-demo
services:
  db:
    type: postgres
```

Start it and Lando wires the database into your app's network:

## Connection details

Other services in your app connect using the service name as the hostname —
here that's `db`. The defaults:

| Setting | Value |
| --- | --- |
| Host | `db` |
| Database | the app name (`postgres-demo`); override with `database:` under `services.db` |
| User | `lando` |
| Password | derived per app (`lando-<hash>`) |

The password is derived per app, so read the exact value from `lando info`
rather than hardcoding it. From inside the app network the connection URL is:

```
postgresql://lando:<password>@db:5432/postgres-demo
```

## CLI access

Declare a tooling alias targeting the `db` service to open the `psql` client:

```sh
lando psql
```

A common companion is a `db-import` tooling alias that pipes a SQL file into
`psql`:

```sh
lando db-import dump.sql
```

## Pin a version

Use `image:` to pin a specific PostgreSQL version when the default
`postgres:16` isn't what you want:

```yaml
services:
  db:
    type: postgres
    image: postgres:15
```
