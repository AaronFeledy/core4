# Add PostgreSQL

Put `type: postgres` in your services block. Lando pulls `postgres:16` and listens on `5432`:

```yaml
name: postgres-demo
services:
  db:
    type: postgres
```

Set `creds:` when you want explicit values. Omit `password` and Lando generates one. Do not assume it is `lando`.

```yaml
services:
  db:
    type: postgres
    creds:
      user: lando
      database: postgres-demo
```

Start it. Lando puts the database on the app network:

## Connect from another service

Other services use the service name as the hostname. Here that's `db`. Defaults:

| Setting | Value |
| --- | --- |
| Host | `db` |
| Database | the app name (`postgres-demo`); override with `database:` under `services.db` |
| User | `lando` |
| Password | generated when omitted; read it from `lando info` |

The password is generated when you omit it, so read the exact value from `lando info`. Don't hardcode it. From inside the app network the connection URL is:

```
postgresql://lando:<password>@db:5432/postgres-demo
```

## Open the client

The `postgres` type ships the `psql` client task. After start:

```sh
lando psql
```

Import a dump with `lando db:import`. See [Import and export app databases](../tooling/db-import-export.mdx). You can still pipe into `psql` with `lando exec`.

## Pin a version

Set `image:` when `postgres:16` isn't the version you want:

```yaml
services:
  db:
    type: postgres
    image: postgres:15
```
