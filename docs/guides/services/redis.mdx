# Redis

Add Redis to your app by declaring `type: redis` in your services block.
Lando pulls `redis:7` by default and listens on the standard TCP port
`6379`. The default command enables append-only persistence
(`redis-server --appendonly yes`) so cached data survives a restart:

```yaml
name: redis-demo
services:
  cache:
    type: redis
```

## Connection details

Connect from another service using the service name `cache` as the
hostname. The default image runs without auth for local dev; add
`--requirepass` via `command:` to require one. From inside the app network
the connection URL is:

```
redis://cache:6379
```

## CLI access

Declare a `redis-cli` tooling alias targeting the `cache` service to verify
it responds:

```sh
lando redis-cli ping
```

Store and read keys directly from the host via the alias:

```sh
lando redis-cli set hello world
```

## Pin a version

Use `image:` to pin a specific Redis version when the default `redis:7`
isn't what you want:

```yaml
services:
  cache:
    type: redis
    image: redis:6
```
