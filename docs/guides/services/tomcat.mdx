# Add Tomcat

Put `type: tomcat` in your services block. That shorthand is Tomcat 11. Lando mounts your app at `/app` and serves the webroot (the project root by default) as the ROOT webapp:

```yaml
name: tomcat-demo
services:
  appserver:
    type: tomcat
```

## Pick a version

Use `tomcat:11` when you want the default major written out. Choose
`tomcat:10` or `tomcat:9` for an older line:

```yaml
services:
  appserver:
    type: tomcat:10
```

## Deploy the webapp

Tomcat follows the same rules as the other web types. The app mounts at `/app` (or `appMount.target`), and `webroot` is relative to that mount. The default is `.`, the project root, so a `WEB-INF` directory at the top of your project is enough. Point `webroot` at an exploded build when the webapp lives deeper, for example a Maven output directory:

```yaml
services:
  appserver:
    type: tomcat
    webroot: target/myapp
```

An absolute container path is also accepted. Lando points Tomcat at the webroot by writing a ROOT context (`conf/Catalina/localhost/ROOT.xml`) during the image build, so the webroot is served at `/`. The image's own `server.xml` stays as is, and a custom `command:` such as `catalina.sh jpda run` still serves the same webroot. One webapp is served; other webapps and WAR drop-ins are not deployed. With your own `image:`, Lando leaves the image's Tomcat configuration alone and writes no ROOT context, so `webroot` only sets `LANDO_WEBROOT`.

`LANDO_APP_ROOT` is `/app`, `lando exec` starts in `/app`, and `LANDO_WEBROOT` is the resolved webroot. Moving the mount with `appMount.target` works like any other type. If the service does not use your app's code, set `appMount: false` and give `webroot` an absolute container path to content the image provides; a relative or omitted `webroot` fails planning in that case.

## TLS and the default route

Tomcat listens on `8080`. Lando gives it a default hostname route and turns
on `lando.certs`, so `lando info` shows an `https://` URL after start. Set
`certs: false` if you do not want a leaf certificate.

```sh
lando info --json
```
