# MariaDB

Add a MariaDB database to your app by declaring `type: mariadb` in your
services block. Lando pulls `mariadb:11.4` by default and listens on the
standard TCP port `3306`:

```yaml
name: mariadb-demo
services:
  db:
    type: mariadb
```

Start it and Lando wires the database into your app's network:

## Connection details

Other services in your app connect using the service name as the hostname —
here that's `db`. The defaults:

| Setting | Value |
| --- | --- |
| Host | `db` |
| Database | the app name (`mariadb-demo`); override with `database:` under `services.db` |
| User | `lando` |
| Password | `lando` |

MariaDB also exports the `MYSQL_USER` / `MYSQL_PASSWORD` / `MYSQL_DATABASE`
env names, so MySQL clients and frameworks connect unchanged. From inside
the app network the connection URL is:

```
mysql://lando:lando@db:3306/mariadb-demo
```

MariaDB speaks the MySQL wire protocol, so that's the right scheme.

## CLI access

Declare a tooling alias targeting the `db` service to open the `mariadb`
client:

```sh
lando mariadb
```

A common companion is a `db-import` tooling alias that pipes a SQL file into
the client:

```sh
lando db-import dump.sql
```

## Pin a version

Use `image:` to pin a specific MariaDB version when the default
`mariadb:11.4` isn't what you want. For example, the 10.11 LTS line:

```yaml
services:
  db:
    type: mariadb
    image: mariadb:10.11
```
