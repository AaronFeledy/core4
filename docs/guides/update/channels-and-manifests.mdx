# Update channels and manifests

## Channel resolution

The stable channel resolves to `https://update.lando.dev/v4/stable.json`. The next channel resolves
to `https://update.lando.dev/v4/next.json`. The dev channel resolves to
`https://update.lando.dev/v4/dev.json`.

## Signed manifest trust root

The updater fetches the sibling signature and certificate for the selected manifest URL:

```text
<manifest-url>.sig + <manifest-url>.crt
```

The manifest signature is verified before any manifest fields or artifact URLs are trusted. A bad
manifest signature stops the update before schema decoding or binary download.

A signed manifest older than the newest signed manifest previously observed for that channel is
refused as possible replay (`UpdateManifestReplayError`).

## Schema and minimum version

`UpdateManifestSchema` validates `channel`, `version`, `minimum`, artifact URLs, checksums,
signatures, and per-platform binary entries. The manifest carries explicit entries for every release
binary platform: `darwin-x64`, `darwin-arm64`, `linux-x64`, `linux-arm64`, `windows-x64`.

A binary older than `manifest.minimum` refuses auto-update and prints official installer plus GitHub
Releases remediation — manual update is required.
