Tooling fragments load through the canonical `includes:` surface with `kind: tooling`. The
`toolingIncludes:` shorthand resolves through the same machinery, so both spellings produce the
same commands wherever both are accepted. Inside a tooling fragment only the `toolingIncludes:`
spelling nests further fragments; a bare `includes:` key in a fragment fails closed with a tagged `LandofileIncludeError`.
