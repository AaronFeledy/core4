# Run Composer on PHP

Declare a `composer` tooling task against a PHP service. Lando routes it through the cache-backed tooling path, so it does not need a provider bootstrap just to find the command:

```yaml
name: composer-php-demo
services:
  appserver:
    type: php:8.3
tooling:
  composer:
    service: appserver
    cmd:
      - sh
      - -c
      - composer "$@"
      - composer
```

## Use the bare name or the canonical id

```sh
lando composer --version
lando app:composer --version
```

Both forms use the same route. The router reads a fresh app command cache before provider-backed execution starts. If the cache is stale or missing, the command names the fix: `lando app:cache:refresh`, `lando start`, or `lando rebuild`. After routing, the normal tooling path still enforces version, provider, environment, and runtime policies.
