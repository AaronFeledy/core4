# Run Composer on PHP

Run Composer inside a PHP service by declaring a `composer` tooling task in `.lando.yml`. Use this complete example in a new app directory, or merge the task into an existing PHP app:

```yaml
name: composer-php-demo
services:
  appserver:
    type: php:8.3
tooling:
  composer:
    service: appserver
    cmd:
      - sh
      - -c
      - composer "$@"
      - composer
```

After completing `lando setup`, run `lando start` from the app directory. Then run `lando composer --version` to check that the task reaches Composer in the service.

## Use the bare name or the canonical id

```sh
lando composer --version
lando app:composer --version
```

Both forms use the same route. The router reads a fresh app command cache before provider-backed execution starts. If the cache is stale or missing, the command names the fix: `lando app:cache:refresh`, `lando start`, or `lando rebuild`. After routing, the normal tooling path still enforces version, provider, environment, and runtime policies.
