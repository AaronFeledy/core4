# JSON Schema artifacts

Regenerate the published schema artifact set: public SDK schemas, command
result schemas, metadata indexes, bundled manifests, and reference docs:

```sh
bun run scripts/build-schema-snapshot.ts
```

Every generated schema document uses draft-07 by default
(`http://json-schema.org/draft-07/schema#`). The indexes
(`dist/schemas/index.json` and `dist/command-schemas/index.json`) cover
every public SDK registry entry and every exact canonical command id, while
each schema file remains standalone.
