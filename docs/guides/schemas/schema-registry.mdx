# The public schema registry

Import `publicSchemaRegistry`, `JSON_SCHEMA_NAMES`,
`publicSchemaMetadataIndex`, `schemaArtifactFilename`, and
`renderPublicSchemaReferencePages` from the canonical SDK schema entry
point:

```ts
import {
  publicSchemaRegistry,
  JSON_SCHEMA_NAMES,
} from "@lando/sdk/schema";
```

Core re-exports the same registry and metadata index from
`@lando/core/schema` without owning a second schema list. JSON Schema
generation reads from `publicSchemaRegistry`, so listed schemas and
generated artifacts stay in lockstep. This registry export contract is
locked by `sdk/test/library/exports.test.ts` and
`core/test/build/schema-snapshot.test.ts`.
