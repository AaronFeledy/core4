# Generated schema reference docs

From the repository root, run the schema snapshot generator to rebuild public
JSON Schema artifacts and Starlight reference pages from the public schema
registry. Edit the owning schema annotations rather than generated pages:

```sh
bun run scripts/build-schema-snapshot.ts
```

Generated Starlight MDX pages live in the reference tree declared by
`publicSchemaMetadataIndex` `docsPath` entries, under
`docs/reference/schemas/*.mdx`. Titles, descriptions, required fields,
accepted values, examples, defaults, and deprecation callouts are all
derived from schema annotations and Effect Schema AST nodes, not hand-written.
